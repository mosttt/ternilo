# Ternilo v0.2.18

This patch improves model selection, questions and approvals, and fixes history loading and model API error explanations.

- Scroll long Ask questions inside the card while navigation, skip and submit controls remain visible. Answers and custom input survive question changes and collapsing.
- Personal-space model defaults apply to new sessions created from Server on connected computers or managed workers. Choose “Choose for each new session” to clear the default. Existing sessions, team spaces and device-local defaults stay unchanged.
- When models are already available, an unconfigured session offers model selection instead of asking you to configure another Provider. New-session actions do not reuse a blank session with a different model.
- Command approvals use a short paragraph with the action and material effects. History and the pending card share the explanation; the full command remains expandable. Older approval formats remain supported.
- Keep partially loaded history when switching sessions, display it immediately on return, and resume older pages. Interrupted initialization retains readable content and recovers automatically.
- Distinguish DeepSeek insufficient balance, OpenAI billing and spending limits, and request rate limits, with actionable guidance. Shared-model errors do not expose raw upstream responses or secrets.

- Wait for Chromium to finish writing its startup endpoint before rendering documents.

The affected interfaces support Chinese, English, Korean and narrow mobile screens.

## Upgrade

Pull `ghcr.io/mosttt/ternilo-server:0.2.18` and recreate the Server container; restarting an old container does not update its image. Update connected computers' `ternilo` as well: stop it, replace the binary or use the original installation method, retain its data directory and configuration, then restart.

No resource-migration activation command is needed. Unfinished resource-migration features and Work are excluded. Desktop installers remain unsigned and unnotarized; automatic updates remain disabled.
