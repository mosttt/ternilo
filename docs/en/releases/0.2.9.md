# Ternilo v0.2.9

This release fixes scrolling on the Server setup page and reduces repeated history reads for Cloud session statistics.

- The setup form has its own scroll area. Desktop wheel input, mobile touch gestures and keyboard focus can reach all database settings, administrator fields and the submit button on narrow and short viewports.
- Fix stale session model menus after adding or editing a Provider in device-local model settings. Updated models are available when returning to the workbench.
- Cloud session statistics use a rebuildable database checkpoint. Unchanged reads return the cached result and appended events are processed incrementally. Regenerated history or invalid checkpoints rebuild from the journal; reads still check current view permissions.
- Live requests combining statistics and full plugin projections retain a shared history view. Full plugin projections still replay history.
- Update collaboration, security and architecture documentation in both languages, restore the older computer management and four Agent mode browser contracts, and include setup regression coverage in release checks.

Six platform targets and desktop installers are included, together with the AMD64/ARM64 Server image `ghcr.io/mosttt/ternilo-server:0.2.9`. The stable release updates `latest` after publication. Desktop signing, notarization and automatic updates remain disabled. Cross-project, cross-team and cross-host resource migration will be delivered separately.
