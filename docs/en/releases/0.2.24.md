# Ternilo v0.2.24

This patch improves Server workbench loading and computer management, with Chinese, English and Korean UI support.

- Show the Server's saved workspace list and navigation before loading the selected computer's conversation and configuration. A slow computer no longer blocks switching computers or opening settings; loading feedback and retry remain in the conversation area.
- Default the workspace picker to the computer selected in the sidebar. Refreshing preserves a manual override. An offline selection shows a clear warning instead of silently creating the workspace on another computer.
- Use the same current-version → Server-release line in My computers and the update dialog: an upward arrow means an update is available, a check means the online computer matches, and an X includes the reason when the status cannot be confirmed or an update is unavailable. Remove the duplicate normal-state sentence and synchronize dialog refreshes back to the list.
- Fix cache invalidation waking old model panels during sign-out and sending requests with revoked credentials. Late responses cannot repopulate a new account or space.

## Upgrade

When upgrading from v0.2.23, Executor protocol 49 and data epoch 1 remain unchanged. Update Server to `ghcr.io/mosttt/ternilo-server:0.2.24` and recreate the container; existing v0.2.23 clients can remain connected. Browser/CLI clients with remote updates enabled can then update from My computers. Update other clients using their original installation method, keeping their data directories and configuration.

Earlier versions still require the coordinated Server/client upgrade described in the [v0.2.23 upgrade notes](https://github.com/mosttt/ternilo/blob/v0.2.24/docs/en/releases/0.2.23.md). For Desktop, install the new package for your platform. Desktop installers remain unsigned/unnotarized, and desktop automatic updates remain disabled.
