# Ternilo v0.2.19

This patch fixes workspace image display and reduces local tools’ dependence on external installations and host settings.

- Render Windows drive paths, file URI references and workspace image filenames containing spaces through authenticated workspace APIs. Paths outside the workspace remain blocked.
- Embed file globbing and text search; installing `ripgrep` is no longer required. Ignore rules, result limits and partial-result notices remain available.
- Decode legacy Windows shell output using the host output code page, including Chinese, Korean and OEM output. Original commands, exit codes and system security policies are retained.
- Mark nonzero shell exits and timeouts as tool failures. Explain PowerShell restricted-method and syntax errors separately while retaining raw output.
- Check the default command sandbox when opening a session on a connected computer. Show where to repair missing or unusable dependencies, an applicable installation command, and a retry action.
- Update Wasmtime to 48.0.7, addressing RUSTSEC-2026-0378 and RUSTSEC-2026-0379.

Related UI is available in Chinese, English and Korean.

## Upgrade

Pull `ghcr.io/mosttt/ternilo-server:0.2.19` and recreate the Server container. Also update `ternilo` on connected computers to receive native search, Windows decoding and sandbox checks: stop the program, replace the binary or use the original installation method, then restart with the existing data directory and configuration. On Windows, update the complete package and keep the sandbox helper beside the main executable.

No database migration or resource-migration enable command is required. Resource migration and Work are excluded from this patch. Desktop installers remain unsigned/not notarized; automatic updates remain disabled.
