# Ternilo v0.2.10

This release fixes local session history being read as incomplete JSON during streaming writes, which could leave the web interface showing a history load failure.

- Independent stores for the same log share access protection. Full, incremental, paged and individual event reads wait for complete records; concurrent readers can still read together.
- Fork writes and log removal use the same protection. Damaged static logs still report errors and retain the existing offline inspection, backup and repair workflow.
- Fix Python SDK reconnection when a Server restart closes TCP during HTTP Upgrade. Total and reconnection deadlines still apply; malformed complete protocol responses and denied access remain immediate errors.
- Retain v0.2.9 setup scrolling, conversation scrolling, Korean translations and Cloud statistics checkpoints. The published v0.2.9 tag remains unchanged.

Six platform targets and desktop installers are included, together with the AMD64/ARM64 Server image `ghcr.io/mosttt/ternilo-server:0.2.10`. The stable release updates `latest` after publication. Desktop signing, notarization and production updates await publisher materials. Resource migration remains separate work.
