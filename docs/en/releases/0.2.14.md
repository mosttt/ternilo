# Ternilo v0.2.14

This release brings plugin parameters into one searchable view and adds collaboration configuration to the team panel.

- **Settings → Plugins** now opens **All settings**, with parameter search and quick navigation. Each plugin can be saved, discarded, or restored to its inherited configuration independently.
- Agent Team includes **Collaboration settings** for the current session's mode, role models, permissions, and child agent limits. All three entry points share drafts, saved settings, enabled state, and inheritance. A shared save lock also prevents conflicting writes when switching entry points during a save.
- Concurrent child tasks and retained child agent instances have separate explanations and a live effective concurrency limit. New labels and hints support Chinese, English, and Korean.
- The team refresh and close buttons are aligned. Opening the panel focuses its title, and narrow screens support native touch scrolling through the complete form and save controls.

Unsaved drafts survive switching entry points and closing the panel within the same page; reloading the page discards them. Current-session settings do not rewrite existing child sessions. Local and Server-connected computer sessions allow editing while running, with saving available after the task finishes or is stopped.

Update CLI/Desktop and Server together; connected computers need a Ternilo version supporting collaboration configuration. Resource migration and recovery remain under separate development. Desktop signing, notarization, and production automatic updates still await publisher credentials.
