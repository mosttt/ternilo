# Ternilo v0.2.12

This patch fixes blank sessions without a removal action and computer-session plugin changes that stayed on “Saving…” while a task was running.

- “New Session” reuses an eligible blank session in the same workspace with matching configuration and no draft, attachments, references or pending work. Rapid clicks share one operation. “Create another session” explicitly prepares additional tasks without a hard count limit.
- Blank sessions have rename, archive and owner-confirmed deletion actions. Cancelling keeps prepared content; deletion preserves workspace files. Unsent attachments and references survive switching sessions within the same page.
- Local/Node plugin configuration explains the wait while a task runs and keeps fields editable, with saving, enabling plugins and removing overrides temporarily disabled. Users with stop permission can stop the task within the form and save their original edits once it actually finishes. The backend promptly returns Conflict and does not cancel a task just to save plugin changes.
- Direct navigation to Server plugin settings receives current activity. Cancellation and failure now publish settled activity so completed tasks cannot leave a stale running notice.

Update the execution computer's CLI/Desktop and Server together for the corresponding UI and backend fixes. The release includes six platform targets, desktop installers and the AMD64/ARM64 Server image. Desktop signing, notarization and production updates still await publisher materials.
