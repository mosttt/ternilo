# Ternilo v0.2.8

This release fixes mobile settings interactions and improves conversation history loading feedback.

- Opening a conversation shows a history loading animation. The first page appears immediately while subsequent pages retain a loading indicator, which ends on completion or failure. Cached conversations still appear directly.
- Plugin switches keep their intended shape with separate pointer targets and visible tracks. Mouse, touch and keyboard interaction work on desktop and mobile.
- Agent presets show a complete read-only Profile including inherited plugins, alongside editable preset overrides JSON. Override changes update the preview while untouched base plugins remain inherited.
- Fix horizontal overflow and clipped text in narrow preset editors.
- Computer details support touch scrolling with cancel and save actions remaining visible. The focused input scrolls into view when the available window height shrinks.
- Both languages document the MCP plugin configuration entry point, and both READMEs include a LINUX DO community link.
- Update DOMPurify to 3.4.16 and source-map-js to 1.2.2 to address published security advisories. The frontend dependency audit passes. See the [DOMPurify advisory](https://github.com/advisories/GHSA-p98j-92pf-mc4p) and [source-map-js advisory](https://github.com/advisories/GHSA-68fv-2mgg-jv7q).

Six platform targets and desktop installers are included, together with the AMD64/ARM64 Server image `ghcr.io/mosttt/ternilo-server:0.2.8`. The stable release updates `latest` after publication. Desktop signing, notarization and automatic updates remain disabled.
