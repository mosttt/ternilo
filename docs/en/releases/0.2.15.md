# Ternilo v0.2.15

This release completes the current collaboration and context improvements, retaining Independent, Assisted and Parallel modes, role models, and synchronized plugin settings.

- The composer context panel shows the latest request's system instructions, tool definitions, conversation, tool output, and reasoning/continuation state. Character counts describe the request after compaction and output budgeting, separately from provider-reported token usage.
- Session logs support per-tool output limits followed by the aggregate history budget, while full outputs remain available as attachments. Code maps can trace direct and indirect candidate callers in selected files, with explicit ambiguity, dynamic-target and truncation diagnostics.
- Optional automatic reasoning control chooses from configured low/medium/high levels for each main-model step. It is off by default, respects the manually selected ceiling, and is checked against trusted model configuration on Server and source computers. It does not switch models or rewrite saved settings.
- GitHub tools add read-only release listings, latest stable releases, tag/ID lookup, and paginated assets. Isolated Workers retain their existing network restrictions.
- Document rendering supports Markdown math with embedded fonts, including offline and minimal-font execution environments. Invalid formulas, external resources and overflowing math still prevent a document review from passing.

New settings and displays support Chinese, English and Korean, including narrow mobile screens. Relevant local, Server-connected computer and existing Worker flows have been validated. Update CLI/Desktop, Server and separately deployed Workers together.

Resource migration and recovery remain on their separate development branch and are not included. Desktop installers remain unsigned and unnotarized; production automatic updates are not enabled.
