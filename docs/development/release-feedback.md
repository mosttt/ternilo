2026-09-29 后续反馈：

- 同机多实例：现有真实 Server／双 Node 浏览器测试已通过；中英文远程接入文档补齐不同监听端口、数据目录、Node ID／Token 和定向停止示例。
- 历史入口原来按 200 条底层事件分页，流式 delta 很快占满，导致普通短对话也被截断。现改为每个 API 请求最多 1,000 条，普通历史（序列小于 10,000）自动读完，较大历史首次及每次追加 5,000 条，Live 从读取尾部独立续接。3 万条本地／Server／离线历史浏览器检查通过。
- 轨迹虚拟列表的 ResizeObserver 对整体高度改变调用 measure，造成测量缓存反复失效；改为仅宽度改变时重测，使用匹配行类型的估算，并让触摸滚动期间暂停追尾。新增真实触摸手势与大列表位置稳定性验收。
- Server CSP 漏掉 blob 图片及预览 frame 来源，导致工作区 PNG 预览失败。允许应用生成的 blob，保留受限脚本策略；HTML 预览移除外部 URL、内嵌用户样式和主动元素，PDF 使用隔离 frame。
- 远程工作区预览在等待 Node 期间撤销共享，原末尾检查引用的是读取前的权限对象。现改为返回前重新查询工作区权限，回归确认响应 403 且不包含私有文件字节。仅共享会话不开放工作区，遍历与符号链接越界检查继续保留。
- 正式中英文文档及开发文档链接门禁通过；打包／部署工具 23 项通过。登录会话字段与撤销／OIDC 实际浏览器流程通过。
