# 发行反馈与交付状态

当前准备交付 `v0.1.1`，优先完成客户端、Server 和 Desktop 的实际使用与发行闭环。源码修复和新增换电脑浏览器回归已通过；对应提交的 CI、四平台产物和 Server 镜像尚待验收。

## 当前结果

- 工作区、Desktop 与 Compose 版本统一为 `0.1.1`。Compose 默认拉取 `ghcr.io/mosttt/ternilo-server:0.1.1`，无需本地构建；该版本镜像随 Release 作业发布。
- 客户端归档命名为 `ternilo-版本-平台`，Server 为 `ternilo-server-版本-平台`。Windows 使用 ZIP，Linux／macOS CLI 使用 tar.gz，Desktop 提供各平台安装器。许可、来源和校验信息随交付物提供。
- 正式文档在源码与便携包中统一放在 `docs/zh-CN/`、`docs/en/`；开发记录仅保留中文，放在 `docs/development/`，不进入发行包。下载说明解释插件 CLI 与 Windows 沙箱辅助程序的用途。
- 主题默认跟随系统，并响应系统主题变化。Node 启动命令使用适合 Bash、PowerShell 和 CMD 的单行 CLI 参数；中文 Node ID 可用，名称参数采用 `--node-id="..."`，命令无法安全表示的字符在登记前校验。
- 对外凭据与公开浏览器会话 ID 统一使用 `ter_` 加用途短码，生成和校验采用相同约定，完整随机值或摘要保持不变。当前格式见[标识命名](../zh-CN/identifiers.md)。
- Windows 状态、预设、工作目录、附件、配置、分叉和扩展保存使用对应平台的文件同步方式。完整退出等待已接受指令收尾，并释放五类本地数据库；Desktop Release 使用 GUI subsystem。
- 浏览器登录会话显示浏览器／系统、首次和最近来源 IP、最后活动、登录及到期时间。无法取得的真实主机名如实显示；转发 IP 只接受显式配置的可信代理。
- 普通历史自动补齐；较大历史首次及每次追加读取最多 5,000 条底层事件，单个请求上限为 1,000。Live 游标独立续接。手机轨迹保留虚拟列表测量结果，宽度改变时重测，触摸滚动期间暂停追尾。
- Server 支持工作区图片预览。HTML 预览移除外部资源与主动内容，HTML／PDF 使用隔离 frame；远程读取返回前重新查询工作区权限，目录遍历和符号链接越界检查继续执行。
- 同机多个实例可分别使用独立监听端口、数据目录、Node ID 和凭据连接同一 Server。工作区显示名在同一账号和项目内唯一；不同电脑选择同名目录时，默认名称加入电脑 ID，显式重名返回 409 和明确消息。弹窗在打开和手动刷新时读取列表。
- 发行作业校验 Windows PE subsystem，并运行实际 Desktop 后台服务的启动、工作区／会话持久化、正常停止和重启检查。

## 验证

已通过本地客户端／Local 235 项测试、前端 945 项测试、Clippy、依赖安全检查、部署／打包工具 23 项测试，以及正式和开发文档链接检查。Windows、macOS Intel／Apple Silicon 持久化检查已通过。

SQLite 与受限 PostgreSQL 的会话详情、相关三项 PostgreSQL 认证／路由检查已通过。实际浏览器已验证登录会话详情与撤销、OIDC、3 万条本地／Server／离线历史、PNG 与隔离 HTML 预览、权限撤销后的文件拒绝、未授权目录及越界拒绝、手机轨迹触摸滚动、主题、PWA 和多实例连接。安装包解压、SDK／插件、账号／模型／历史与快照恢复验收已通过。Linux Desktop 后台服务实际验收已通过。

新增简写命名和工作区冲突修改已通过针对性的单元测试、SQLite 与受限 PostgreSQL 检查，以及原生登录、OIDC、模型设备授权和换电脑的实际浏览器验收。换电脑回归包含旧电脑离线、同名目录默认名称、409 提示后重试、再次打开保持名称及没有列表轮询；目录弹窗单元测试 11 项通过。最新 Clippy、类型检查、构建与文档门禁通过。交付版本以其对应的完整 CI 和发行产物验收为准。
