# 单用户模式的注册设置展示

状态：2026-10-01 独立分支修复和验证完成，供后续合并。

账号页在单用户模式下展示注册方式和审核开关，是注册配置组件保留多用户预配置表单导致的界面问题。Control 的原生注册、OIDC 新账号登记与邀请注册仍要求多用户模式；原生注册在事务开始前和事务内都复核访问模式。

现在单用户账号页只显示“仅实例所有者可以访问，不能注册新账号”的说明，不挂载设置编辑器或邀请面板，也不请求对应设置。切到多用户模式时重新读取原有注册策略；切回单用户时卸载编辑器，不改写数据库中的策略。

受影响注册面板与账号页 18 项单元测试、TypeScript、i18n 和正式文档检查通过。真实 Chromium 配合真实 Server 验证单用户即使保存了开放策略仍返回 403，账号页没有注册或邀请控件且不读取设置，多用户显示保存的开放／审核策略并可改为邀请模式，切回单用户后策略保持。控制台和页面 HTTP 检查通过。

新前端通过独立浏览器产物验证，Server 使用已完成阶段的本机测试程序；没有修改用户运行的实例或 main 测试基线。
