# 跨电脑模型用量汇总

状态：源码、双库合同、单／双 Server 真实浏览器与 CSV 验收通过，已随当前 v0.2.3 公开交付。

范围是 Server 已保存的跨电脑模型请求及来源电脑尝试报告，不是设备整机日志，也不与平台模型账本混算。当前空间与有效账号权限先过滤，仅实际提交者或模型所有者能读取有关记录；资源管理者、空间管理员不会自动获得其他人的报告。

列表、汇总和导出统一使用请求接受时间的 UTC 月份与相同搜索条件。逻辑请求按唯一请求计数，真实重试按尝试计数；未完成和部分 Token 回执保持未知／覆盖次数，迟到报告在刷新后反映。汇总覆盖全部符合条件的记录，不受明细分页影响。明细读取使用只读事务，并把过期租约投影为连接中断，不再在 GET 中批量写入失败状态；真实的迟到完成仍可更新最终结果。SQL 在数据库中聚合，最多返回 10000 个路由／身份／模型组合，超限明确要求缩小查询，不截断总计。

导出保留执行电脑、模型来源电脑、实际提交者、模型所有者、原资源所有者、Provider／模型／协议和计数覆盖率，区分总计行与分项行。文本字段复用已验证的 CSV 引号／换行／公式前缀处理；缺失数值为空，已报告零为零。不写入请求正文、上游地址和 Key。

界面沿用按需加载：展开跨电脑调用后才请求汇总；修改月份／搜索或手动刷新后更新，翻到另一页不重复获取全月汇总。账号／空间变化取消旧请求并丢弃迟到结果。没有自有电脑的协作者也能选择月份和读取自己有权查看的跨电脑记录。

本机验证路径和最终结论随验收补充。v0.2.0 候选 `59dd117` 不包含本项，继续独立推进，不用等远程构建。


## 验收结果

SQLite 与受限 PostgreSQL 合同覆盖：提交者／模型所有者可见、仅资源所有者不可见、跨空间隔离、月份与迟到报告归属、重试不增加逻辑请求、部分／未知计数、重复回执拒绝、租约过期只读投影及最终完成、移除成员后拒绝访问。原 Edge 双库合同 3 项、前端 CSV／身份隔离 5 项通过；Clippy、TypeScript、i18n 和正式文档检查通过。

真实 Chromium 单 Server SQLite、双 Server 受限 PostgreSQL 均使用两台 Node 完成模型／工具任务、服务账号身份、来源离线重连，并逐项将整月汇总与完整原请求／尝试记录核对。实际下载 UTF-8 CSV，确认电脑名称、服务账号与独立请求数，未泄漏来源 Key；1440／390／320 页面无横向溢出。证据分别在 `/tmp/ternilo-forward-summary-browser/computer-model-forwarding` 和 `/tmp/ternilo-forward-summary-diagnostic/computer-model-forwarding`。

一次并行验收在读取会话事件时出现跨 Server 503，发生于汇总接口调用前；旧错误没有区分传输、HTTP 状态或解码。已加不包含 URL／凭据／响应正文的服务端分类日志和验收进程退出信息，随后完整 PostgreSQL 复验通过。本次未重现原故障，不能宣称根因已修复，纳入后续模型／并发压力验证。
