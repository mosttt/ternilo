# 预设 Profile 展示与开关尺寸

2026-10-07：用户截图显示预设插件开关变成黑色竖向圆角块；高级区标为“完整 Profile JSON”，实际只显示标准预设的 `code-mode` 覆盖项。

开关使用独立的 40×40 点击／键盘焦点区域和 36×20 可见轨道。通用设置按钮的最小高度不再拉伸轨道，移除旧手机伪元素轨道，浅深主题和两种状态共用同一结构。

预设保持基础继承与覆盖的保存规则：完整只读预览与上方插件卡片一致，可编辑区域准确标注为“预设覆盖 JSON”。字段修改和 JSON 覆盖变化实时更新完整预览；未编辑的基础项不复制到覆盖中，删除覆盖项恢复继承。首次 MCP 接入说明同步指向可编辑覆盖区域，没有新增对外 MCP Server 需求。

另外修正预设编辑区的窄屏横向溢出：滚动区使用可收缩的单列，插件 kind 允许换行，滚动到右侧控件或完整预览时不再把左侧文字移出弹窗。

电脑详情原来由不可滚动的弹窗直接容纳全部字段，内容超高后被裁切。现在标题与底部操作区保留位置，中间内容支持触摸滚动；窗口高度变化时，让当前输入框保持可见。滚动观察器在实际内容节点挂载时注册并清理，避免 Portal 延后挂载造成观察器未注册。

真实 Chromium 使用公开 v0.2.7 CLI／Server 的独立临时实例和本次构建的 Web 资源，通过两项定向合同：预设覆盖修改／完整预览／禁用与空格键恢复／禁用 MCP 配置保存，覆盖中英文、浅深主题、1440／1280／700／390／320 宽度；电脑详情在 430／390／320 宽度下实际派发触摸滑动，缩小高度后保持输入与操作可见，保存备注后与真实 API 核对。页面及网络错误为空，截图已复核；没有替换用户安装程序或运行实例。本机临时资源载入只用于开发验收，没有加入正式 CI 或部署要求。
