# v0.2.8 发行验收

2026-10-07：本次发行包含会话历史加载提示、插件开关尺寸、预设完整 Profile 与覆盖编辑区、窄屏裁切，以及电脑详情的手机滚动与输入焦点修复。相关实现已合入 main，v0.2.7 的公开标签保持原源码。

发行准备发现主分支检查的两个浏览器合同失败：历史测试在已折叠的处理过程内直接点击思考行；共享撤权测试收尾移除拦截规则时，Playwright 自动继续了仍在获取响应的请求，随后测试再次回填而报错。前者改为先展开实际处理过程，后者直接观察浏览器真实读取响应，并等待权限拒绝响应的 JSON 验证完成，不再拦截或重复发送元数据请求。完整思考文本、缓存无重复读取、权限拒绝响应及无后续事件的断言保留。

依赖审计发现 DOMPurify 与 source-map-js 的上游安全公告，分别更新至 3.4.16 和 1.2.2，没有增加审计豁免。版本、锁文件、中英文发行说明、部署镜像与下载示例同步为 0.2.8。两项移动设置合同加入现行发行浏览器检查。

CLI／Server 匹配原生构建通过，程序版本均为 0.2.8，更新后的前端资源已重新嵌入。初次本机双任务构建在编译 cranelift-bitset 时收到 SIGKILL，原因未确定；重试使用本机单任务，不把该设置写入项目标准流程。
