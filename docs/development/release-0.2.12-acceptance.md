# v0.2.12 发行与验收

2026-10-11。沿用用户“完成后发版”的授权，将已验收的空白会话管理与运行中插件保存修复作为补丁交付。资源迁移 1–5 的底层改动保留在独立工作树状态，不包含在本次提交或发行中。

v0.2.12 已于 2026-10-12 公开并完成产物验收。[发行页面](https://github.com/mosttt/ternilo/releases/tag/v0.2.12)、[Release 流程](https://github.com/mosttt/ternilo/actions/runs/38148310838)和 main Checks 均成功。标签固定指向 `5786b5be5c8b03a0ab7a017cf9f772e1249d8b2e`；源码版本、归档 SOURCE 和镜像 revision 一致，标签未移动。

空白会话实现和桌面／320×560 纯触摸验收见[会话记录](blank-session-lifecycle.md)。插件保存的原因、实时提示、保留编辑、表单内停止及及时拒绝见[插件记录](plugin-save-while-running.md)。插件修复的 6 项 Rust 交互合同、28 项前端合同、类型／i18n、Local 全目标 Clippy 和两个真实浏览器合同通过；本机及 Server＋Node 的忙碌拒绝分别为 5 ms／148 ms，页面、控制台与 HTTP 错误均为空。

版本同步包括 Cargo workspace、21 项 lock package、Tauri、部署默认值和双语当前部署／打包说明。v0.2.11 的公开标签、附件和历史说明保留原位。Desktop 签名、公证及生产自动更新继续等待原已暂缓的发行者资料。

发行门禁及公开产物结果已完成；下方保留门禁期间发现的问题与修正依据。

首轮 main Checks 的 Rust、SDK、受限 PostgreSQL、依赖及四组平台检查通过，完整浏览器门禁在工作区菜单断言处失败：实际包含本次批准新增的“另建会话”，旧合同仍仅期待“查看位置／重命名／移除工作区”。同步这一精确菜单预期，保留原交互及错误断言。匹配发行源码的隔离本机工作台复测两项通过，共 102.05 秒，包含流式对话、轨迹、滚动、手机布局及空闲连接；随后再次进入 main 门禁。首轮失败记录不作为发行通过结果。

补查其他会话创建合同，发现 Agent 预设的准备步骤仍等待普通新建的 POST，而新策略会复用打开工作区时已经创建的空白会话；隔离浏览器复现该旧合同超时。准备步骤现在直接等待首个会话；需要独立记录的 Node 路由合同改为通过工作区菜单“另建会话”明确创建，保留 POST、身份、权限和文件执行断言。四种 Agent 模式及双语界面复测通过（22.52 秒），受控 PostgreSQL／实际 Node 的浏览器合同通过（112.59 秒），包括双电脑、模型转发、成员执行及只读越权拒绝。测试修正独立提交，资源迁移的配置路由工作树改动继续排除。

后续 main 门禁通过前三组浏览器中的其他合同，工作区登记合同在“重复打开同一文件夹后应有三个会话”的旧预期处失败。实际保留了两个会话并正确复用当前电脑的空白记录。合同现精确检查前后会话 ID 完全一致、复用记录被选中、两个工作区及名称保持不变，复测通过（43.13 秒）。后续两组共十二项浏览器合同也完成本机复测：首批八项通过，四项仅因旧合同未使用浏览器路径覆盖及 Python 缺 WebSocket 依赖而未进入相应流程；补齐本机隔离依赖后四项全部通过（51.96 秒）。本机依赖准备没有写入项目测试脚本或 CI。


公开验收于 2026-10-12 完成：42 个附件的大小、GitHub SHA-256 和 SHA256SUMS 全部匹配。12 个 CLI／Server 归档的程序架构、版本和各 107 个正式文档文件与标签一致；9 个安装器格式校验通过。双架构镜像可匿名读取，`0.2.12` 与 `latest` 指向相同索引 `sha256:5e2f223691ef02fb514be7e1d34d0140e60a33506a72668861a5e84b23d530d1`。公开镜像实测通过非 root、只读根目录、初始化、登录、设置、内嵌 Web 与持久数据重启。

直接解包公开 Linux x86_64 CLI／Server 后，空白会话与运行中插件保存两组、共四项真实浏览器合同通过，分别耗时 19.94 秒与 12.54 秒。Local／Server＋Node 的忙碌保存拒绝响应为 11 ms／33 ms，运行和编辑均保留；包含 320×560 手机触摸交互。页面、控制台和 HTTP 错误均为空。首轮公开程序复测曾在桌面切换到手机宽度时出现侧栏按钮不可见超时；独立诊断复现未出现，随后原始双组合同完整通过，未改动程序或放宽断言。首轮失败日志单独保留。
