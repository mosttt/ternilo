# 后续任务与能力边界

本清单区分默认分支已交付能力、待完成工作、待调查问题和未排期扩展。已公开版本见[发行说明](../zh-CN/releases/0.2.29.md)，当前补丁见[v0.2.29 验收](release-0.2.29-acceptance.md)。Work 不在当前实施范围；既有可选 Worker 的恢复和执行环境仍单独保留。

## 当前开发

模型级网页配置已实现并通过本机／Server Node、跨电脑及中英韩浏览器验证，尚未发布：Provider 默认值与模型独立覆盖、统一外部集成选项，以及取消内置搜索的模型名称白名单。技术状态见[Provider 网页访问](provider-web-access.md#模型级配置)。

独立维护通道已实现并通过隔离签名升级闭环，随 v0.2.30 候选准备发行：执行协议不匹配时保留电脑更新能力，首次启用需手动升级到 v0.2.30。技术状态见[维护通道](client-maintenance-channel.md)。

## 当前公开版本

v0.2.29 已公开 DeepSeek 独立搜索／抓取、Responses 内置搜索和 Provider 统一网页配置，完成本机、Server Node、跨电脑、三语及真实 SDK 的公开成品验收。对应第 35、29 项的 DeepSeek 部分，其余协议与供应商保留原边界。首次升级需统一更新 Server 与电脑端，见[发行验收](release-0.2.29-acceptance.md)。

v0.2.28 已合入 main 并公开，交付模型转发保活与请求诊断、Responses 可选参数、空文件及父目录写入、混合语言历史检索，以及具名只读验证、进程临时目录、Rhai 结构化失败和图谱精简。完整 CI、公开包验签、三语浏览器和正式跨版升级已通过，见[发行验收](release-0.2.28-acceptance.md)。未发布 v0.2.27 的浏览器保存等待条件已确定性修正，证据见[候选记录](release-0.2.27-acceptance.md)；尚未确定原因的历史和原生偶发检查保留为调查项。后续工作按下列范围与顺序推进。

## 实施顺序

依次处理 **8 → 9 → 10 → 11 → 12 → 13 → 14 → 15 → 20 → 6 → 7**。Desktop 签名、公证和完整实机安装依赖相应发行者资料与设备。额外供应商、原生移动包和未排期扩展不构成本补丁的交付范围。

原 1–5 项资源迁移与恢复已撤销并移出计划，其余任务沿用原编号。同空间工作区管理项目迁移、同团队管理权交接和项目共享继续保留。
