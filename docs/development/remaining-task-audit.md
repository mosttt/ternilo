# 后续任务与能力边界

本清单区分默认分支已交付能力、待完成工作、待调查问题和未排期扩展。已公开版本见[发行说明](../zh-CN/releases/0.2.33.md)，当前补丁见[v0.2.33 验收](release-0.2.33-acceptance.md)。Work 不在当前实施范围；既有可选 Worker 的恢复和执行环境仍单独保留。

## 当前公开版本

v0.2.33 已公开委派会话联动归档、单条永久删除、历史流式恢复与执行事实索引、完整文件下载、插件留存上限、子 Agent 连续追问轮次修复及插件草稿竞态修复。完整发行门禁、公开包验签、九项成品浏览器用例与正式跨协议升级取得通过证据；首轮两项浏览器异常保留为调查项 45–46，见[发行验收](release-0.2.33-acceptance.md)。v0.2.32 门禁失败后未公开发行。

v0.2.31 已公开子会话同步、授权回答、预设查看与锁定、Responses 图像错误提示、流式阅读位置、子 Agent 活动状态及升级失败恢复修复，并更新安全依赖。完整检查、六目标打包、镜像与签名发行通过，见[发行验收](release-0.2.31-acceptance.md)。

v0.2.30 已公开模型级网页继承／覆盖、统一外部集成选项、移除模型名称白名单，以及独立客户端维护通道。公开包验签、六项真实成品浏览器测试和双架构镜像验收通过，见[发行验收](release-0.2.30-acceptance.md)。首次需手动统一升级；此后任务协议不匹配时，维护在线的电脑仍可远程更新。技术状态见[Provider 网页访问](provider-web-access.md#模型级配置)与[维护通道](client-maintenance-channel.md)。

v0.2.29 已公开 DeepSeek 独立搜索／抓取、Responses 内置搜索和 Provider 统一网页配置，完成本机、Server Node、跨电脑、三语及真实 SDK 的公开成品验收。对应第 35、29 项的 DeepSeek 部分，其余协议与供应商保留原边界。首次升级需统一更新 Server 与电脑端，见[发行验收](release-0.2.29-acceptance.md)。

v0.2.28 已合入 main 并公开，交付模型转发保活与请求诊断、Responses 可选参数、空文件及父目录写入、混合语言历史检索，以及具名只读验证、进程临时目录、Rhai 结构化失败和图谱精简。完整 CI、公开包验签、三语浏览器和正式跨版升级已通过，见[发行验收](release-0.2.28-acceptance.md)。未发布 v0.2.27 的浏览器保存等待条件已确定性修正，证据见[候选记录](release-0.2.27-acceptance.md)；尚未确定原因的历史和原生偶发检查保留为调查项。后续工作按下列范围与顺序推进。

## 实施顺序

[子会话同步与运行交互修复](agent-runtime-reliability.md)及[跨代码、逻辑与实际页面的项目审查](project-review-2026-11.md)已完成，四项新增审查发现已修复并随 v0.2.31 发行。界面项 8–10 已交付，其余任务保留原编号。

本轮[会话生命周期与执行性能优化](session-lifecycle-performance.md)已随 v0.2.33 交付：委派归档、单条删除、流式历史恢复及 Sessions@2 事实索引。同开发构建隔离负载下，启动 RSS 降约 28%，长历史任务 p50 降约 32%、委派总耗时中位数降约 20%；无启动提速结论。补充交付完整文件分块下载、插件内生成文件留存上限及子 Agent 连续追问的独立轮次与授权来源。旧 Sessions 核心插件需适配并重新编译；执行协议升级为 52，Server／Node／Worker 配套更新，新的子输入来源日志不能由旧版读取，降级需要升级前备份。

后续依次处理 **11 → 12 → 13 → 14 → 15 → 20 → 6 → 7**。Desktop 签名、公证和完整实机安装依赖相应发行者资料与设备。额外供应商、原生移动包和未排期扩展不构成本补丁的交付范围。

原 1–5 项资源迁移与恢复已撤销并移出计划，其余任务沿用原编号。同空间工作区管理项目迁移、同团队管理权交接和项目共享继续保留。
