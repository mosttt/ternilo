## 已完成，不再列为未实现

- 单用户模式不显示注册设置及邀请控件；后端继续拒绝注册。用户重新编译后确认问题修复。
- 默认按电脑分组、组折叠保存、在线资源在状态／Live／搜索／归档读取前过滤，关闭筛选后加载全部可见资源。
- 状态标识移到电脑行，内部工作区不重复显示；工作区分组保留各自状态。在线筛选显示未选中边框和选中勾选。导航到设置／文件／模型／管理页及浏览器返回／前进关闭菜单，保持缓存；真实浏览器、控制台和 HTTP 检查通过。
- 会话切换的有界内存缓存、首屏立即展示与 Live 续接、长单轮历史补齐、补读失败重试游标、思考展开保留、流式更新合并；本机与 Server 共用。
- 目标仅由用户显式 `/goal` 启用；模型不能自行新建或重启目标。
- 本机／Node 和 Cloud 的停止并发送快速确认、持久重启意图、执行权释放后的续发与后到停止优先。
- 本机、Server、可选 Worker 的总配置与分类目录；Server／Worker 使用 `--config-dir`。Work 只保留目录设计。
- 同团队资源管理权交接，保持存储／执行身份和历史归属；真实浏览器与受限 PostgreSQL 验收通过。
- 已纠正管理权交接、跨 Server TCP／PostgreSQL 及本机环境的滞后记录，同步中英文产品边界与 Cloud 停止并发送行为。
- 电脑管理支持名称／备注、按需详情、原凭据暂停／恢复及保留历史的移除登记，侧栏和目录选择器使用显示名；SQLite、受限 PostgreSQL 和真实浏览器验收通过。凭据轮换未做，仍为后续项。
- 此前许可证、发行包格式与命名、双语正式文档、Windows 持久化／终端窗口、登录会话详情、同名目录冲突、图片预览和手机轨迹问题已有实现及对应验证。v0.1.3 发行状态见[发行记录](release-feedback.md)，本阶段新增行为见[工作台记录](workbench-performance-and-layout.md)。

2026-10-03：优先级 1 的当前实现阶段通过，包含电脑管理、统一本站会话、服务账号资源／Live／SDK 权限、电脑模型转发与托管模型委托。下一步集中检查并发行这一阶段，2 级本批功能已完成，继续 3 级账号安全与交付能力。签名、公证所需发行者资料尚未配置在仓库 Secrets，不能据此假定存在可用证书。
