# OIDC 浏览器来源与公网地址

## 当前行为

- 发起授权前检查 Web Crypto，缺失时显示中英文操作提示，保留已有登录状态。
- 当前页面与回调地址必须同源；协议、主机或端口不同均拒绝跳转，避免回调丢失 sessionStorage 中的 PKCE 和 state。
- 登录、账号绑定、回调错误共用错误键映射，不再把浏览器运行异常显示为身份提供方拒绝。
- 设置页面与 Server API 拒绝通配监听地址。设置提供实际 HTTPS 访问地址与回调登记说明；无效地址不显示为可用回调。
- 读取已保存或部署配置中的无效公网地址时停用 OIDC，保留密码登录以便所有者修复。已有 Turnstile 仍执行验证。

## 验证

前端 OIDC 与登录组件定向测试 44 项通过，类型检查、国际化检查、正式文档检查和生产构建通过。Rust 的 HTTPS／显式回环 HTTP／通配监听地址测试通过。

实际 Chromium 验收两项通过：`server-oidc-origin-browser-e2e.test.mjs` 使用真正的非安全浏览器来源和隔离 Server，覆盖加密能力缺失、不同源回调、无效地址的表单／API 拒绝、密码登录与错误部署地址的恢复；`server-security-browser-e2e.test.mjs` 覆盖正常授权码 + PKCE、持久 Client Secret、Turnstile 和设置恢复。检查了手机登录提示、设置表单、控制台与网络请求。身份提供方使用本地签名测试服务，未访问用户生产应用或凭据。
