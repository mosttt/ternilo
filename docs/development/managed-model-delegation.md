# 托管会话模型委托

2026-10-03，本阶段功能与验收完成，待发行。对象是 Server 保存上游凭据、可选 Worker 执行任务的托管会话；电脑模型仍限定远程电脑会话，Work 保持预留。

## 当前行为

有配置权限的协作者可以明确选择自己的账号 Provider 或平台授权。已有来源保留实际模型提供者，账号选择使用带 `owner_user_id` 的 `account_provider`，不能通过同名 Provider 重解释为资源所有者的模型。选择器区分自己的目录与此会话已经获准使用的来源；协作者不能浏览或改选他人无关的私有 Provider 或预算。

工作区存储、执行身份和任务额度归原资源所有者；模型来源和平台预算归实际提供者；请求归实际提交者，含明确授权的服务账号。Worker 不取得上游 Key。开始调用、每次重试及运行期间检查提供者仍有会话配置权限、原作者仍有提交权限；平台授权另需允许资源共享。撤销来源配置权限会中止模型调用，即使提交者仍能使用工作区。子任务保留原始作者、授权根会话和模型提供者。

## 验收同时修复的问题

PostgreSQL 下，部分成功的 Worker 目录读取超过接口原先 3 秒等待，被误报为不可用；等待每次都重做完整授权查询。现在等待按命令自身有效期计算，轮询只读取原执行所有者的命令记录，回传前重新核验会话及工作区权限；运行中子进程读取也不超过原命令期限。新增“读取等待中撤权，迟到结果只对所有者可见”的 SQLite／受限 PostgreSQL 合同均通过。

模型目录刷新期间保留当前展示，已有缓存时不闪现加载行，避免慢响应改变父菜单高度而关闭正在使用的子菜单。所有实际选择及执行仍在后端重新授权。

上述验证使用隔离目录和数据库；没有改动正在使用的实例。电脑凭据轮换按用户要求后移。后续按既定优先级继续供应商托管工具、搜索服务、外部代理和其余 3 级任务。
