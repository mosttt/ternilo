# 工具上下文预算、文件缓存与代码图谱

2026-10-12。会话日志插件增加 `max_tool_history_chars`，默认 48000 字符，0 可关闭总量限制。模型历史优先保留最近的工具结果，缩短较早的结果但保留调用／返回配对。此预算不更改持久历史和大输出附件；单条结果继续采用原有 `max_tool_result_chars`。预算按字符计算，不声称等于 Token 数。

本地文件插件增加 `read_cache_bytes`，默认 0。开启后，每个会话按字节预算复用完整文件内容并淘汰较早使用的条目。每次仍解析工作区路径、打开文件并检查文件类型、大小和版本；工具写入主动失效，外部变更通过元数据失效，读取前后版本不一致时不放入缓存。Unix 版本包含设备、inode、修改时间和变更时间；其他平台使用大小、修改时间与创建时间。不缓存搜索、目录、Shell、写入结果或执行错误；缓存不跨会话共享，也不绕过工具授权。

`ternilo.tools.code_map` 提供只读 `code_map` 工具，解析显式选择的 Rust、TypeScript／TSX、JavaScript／JSX、Python、Go 文件，返回 AST 符号、所属关系、导入及调用源位置。调用边保留语法目标，不推断动态调用的实际类型。语法错误、文件读取截断或结果条目达到上限均明确标记。默认一次 16 个文件、每文件 256 KiB，限制可配置。Local 默认提供该插件；托管 Worker 预设默认关闭，需要在会话启用且由 Worker 策略允许。Work 不增加执行实现。

当前验证：五种语言与 TSX 的实际 AST 合同通过，覆盖注释中的伪代码不被识别、符号和调用位置、未完成语法。工具预算配对、文件读取缓存失效及大输出重启恢复四项定向 Rust 测试通过；Builtins／Local／Cloud 全目标 Clippy 通过。前端类型、三语及 11 项设置／内置元数据测试通过。三个执行程序构建通过。真实浏览器合同在 Local、Server＋Node、Server＋Worker 上验证了超长工具结果的实际模型请求不超过配置预算，以及发现并调用代码图谱后读取到 AST 符号和调用；本机中英韩设置保存及 320×560 滚动通过，页面、控制台及 HTTP 错误为空。


连续保存验收发现旧生命周期检查会将元数据读取误报为运行中任务。保存现在先检查运行锁，再等待短暂的生命周期读取；任务运行仍立即拒绝，配置操作等待超时使用独立提示。4 项插件相关 Rust 回归测试通过，包括等待空闲读取、活动交互不被取消和原子配置校验。最终三语浏览器连续保存通过。

保存的原有两项浏览器回归也通过：Local／Server Node 在运行中分别于 4 ms／14 ms 返回冲突，不取消任务，草稿保留；完成或从设置停止后可保存，手机交互也通过，页面／控制台／HTTP 错误为空。

## 2026-10-15：单工具预算与候选调用影响

会话日志增加可选 `tool_result_limits`，按完整工具名称覆盖默认单条字符上限，随后继续应用总预算。新上限包含截断说明，也约束中断后补出的缺失结果；不配置时保留旧的历史派生和默认截断行为。较低上限将完整结果保存为附件，较高上限可替代默认值；无效配置不覆盖已保存值。前端 JSON 配置、默认上限和错误提示提供中英韩文。

代码图谱增加 `impact_symbol` 和 `impact_depth`。在已读取文件内建立反向调用索引，按名称追踪候选调用者，已访问名称去重，保留调用位置与直接／间接层级。报告包含重名声明、未知动态目标、读取／语法／截断诊断和深度限制。不选择影响查询时保留原图谱结果；不增加运行项目代码或访问工作区外文件的能力。

单工具预算 2 项、完整输出重启恢复 1 项、图谱与影响查询 4 项、工具历史回归 8 项定向测试通过；设置组件 13 项、TypeScript 和三语检查通过。本机／Node／Worker 浏览器合同验证实际模型请求每条文件结果不超过 256 字符、总量不超过 1024 字符，并读取到直接与间接候选调用者。三语设置的无效值阻止保存、有效值保存及手机滚动通过，页面、控制台与 HTTP 错误为空。截图和最终构建已验；详见本阶段数值记录。
