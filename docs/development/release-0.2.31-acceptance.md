## 公开程序的浏览器验收

使用实际下载并验签核对的客户端／Server，在隔离实例与受控模型端点上执行七项浏览器用例，全部通过：

- Server 账号 Provider 的子 Agent 网页设置解析、手机授权、父子会话登记和错误会话回答拒绝。
- 空白会话切换预设；已开始会话锁定预设，同时保留查看、编辑及新会话默认值操作。
- Provider HTTP／SSE 错误及图像复杂度拒绝，三语展示、安全原因传递和无效参数不重试。
- 本地流式回答的小幅滚轮／触摸阅读、完成时保持阅读位置和主动恢复底部跟随。

用例检查页面错误、控制台及相关网络请求。已查看公开程序生成的手机预设、子 Agent 授权、图像错误和触摸滚动截图。

## 正式跨版升级

使用公开 v0.2.30 客户端和 v0.2.31 Server，通过真实 Server 更新接口取得正式签名包，在隔离 Supervisor 实例中完成 0.2.30 → 0.2.31 升级。新版启动人为延迟 45 秒，Server 最终报告 `completed`、版本 0.2.31，任务连接恢复，本机健康查询一致。

更新辅助进程释放操作锁后，重新启用原 Supervisor 配置成功；随后通过 Server 新建工作区与会话，实际写入文件成功。升级没有触碰其他实例。

新增的七项恢复回归分别验证标记写入失败、安装失败且报告失败、配置写入失败、安装后的进度写入失败、回滚报告失败、无法验证原程序时保留保护标记，以及从保存计划恢复损坏配置。受影响包的严格 Clippy、35 项 WASM 扩展测试与文档工具回归通过，详见[项目审查](project-review-2026-11.md)。

## 使用边界

维护协议、执行协议和数据代次不变。已启用远程更新的 v0.2.30 客户端可从 Server 升级；更早客户端仍需手动安装。Desktop 安装器仍未签名，自动更新保持关闭。

Responses 图像 `complexity` 拒绝需要上游或中转修正图像配置；本版提供准确说明并避免重复发送同一无效请求，不改变对话推理参数。历史调查项 11–15、43–44 保留原状态，本轮检查通过不作为其历史根因已确定的证据。
