版本统一为 0.2.17，包括 Cargo／lockfile、Desktop、Compose 示例和发行说明。前端从发布分支源码重新构建，避免携带资源迁移分支中尚未发行的界面。

本轮功能与原验证见[运行反馈修复](runtime-feedback-repairs.md)。发行复用完整 Checks、六目标包和双架构 Server 镜像流程，增加真实运行反馈浏览器合同到现有浏览器检查。[PR #7](https://github.com/mosttt/ternilo/pull/7)通过[完整检查](https://github.com/mosttt/ternilo/actions/runs/39096855443)后合入 main；[正式发布流程](https://github.com/mosttt/ternilo/actions/runs/39099664217)全部通过，[v0.2.17 已公开发布](https://github.com/mosttt/ternilo/releases/tag/v0.2.17)。标签与主分支的发行提交为 `03499a86bd5b8733791003330c6500b3f416f97e`。

独立发行分支验证补齐了 Node 在线状态投影、离线配置请求与工作区面板的配套调用。首次真实浏览器检查发现断线后工作区面板仍发送请求并收到 503，已补齐离线门控；草稿保留与重连配置恢复也纳入相关测试。

依赖门禁首次失败于新收录的 `RUSTSEC-2026-0370`、`RUSTSEC-2026-0371`、`RUSTSEC-2026-0372`。原公告均为 `unmaintained`：`zvariant`、`zbus_names`、`zvariant_derive` 的能力合并进 zbus 6，不是漏洞公告。2026-10-18 核对 crates.io 的最新 Tauri dialog 2.8.3、notification 2.7.0、single-instance 2.5.4 及其上游，仍要求 zbus 5；没有兼容的依赖升级路径。本版按现有桌面传递依赖政策仅豁免这三个维护公告，保留所有漏洞、许可证及来源门禁；待 Tauri 插件迁入 zbus 6 后移除对应豁免。CLI 和 Server 不引入这组桌面依赖。

完整 Rust 门禁另发现既有 Worker 孤儿进程恢复测试把“仍在写入”的观察窗口固定为 60 ms，在并行 CI 上误判；失败后仍持续出现写入日志，证明子进程实际存活。测试改为在 5 秒内等待实际写入增长，再执行原恢复流程；存活、停止写入及重复恢复断言保留，失败断言也在清理后执行，不改生产恢复逻辑。

后续浏览器门禁发现新加“上级目录”按钮在窄屏只有 32 px，已改为 40 px 点击区域；沿用原有三种手机／横屏尺寸检查。文件页原 Local／Server 浏览器合同同步到“一项文件、展开两版”的交互，保留上传字节、旧版下载、分页、归档、权限隔离和离线错误验收，并加入同一 CI 浏览器门禁。

项目移动浏览器检查发现断线／撤权期间的响应体读取竞态：浏览器取消旧请求后，测试仍尝试读取已丢弃的响应体。现在先等待请求完成，显式记录 `net::ERR_ABORTED`；仍只接受对应会话、撤权阶段的 400／403 或重连阶段的 503，完整响应继续核对错误类型和内容。项目移动的历史、文件、权限撤销和重连检查本机通过。

授权原因曾仅展示沙箱术语和长命令，无法判断用途。补丁新增 shell `approval` 说明（操作、用途、影响），要求模型使用用户语言并说明完整操作和实际影响；等待授权卡与历史共用组件，完整命令折叠查看。宿主授权条件不变，旧调用参数兼容；缺少说明时明确提示。42 项相关前端测试、类型、三语和文档门禁通过，真实三语授权／拒绝流程通过：拒绝后没有写入，允许一次后才产生预期文件，窄屏按钮和完整命令均可访问。
