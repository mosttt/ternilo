# Linux 进程退出与清理竞态

2026-10-05：v0.2.7 未公开的发行检查在五个 Claude hook 生命周期测试的最终 shutdown 失败，错误为 `observe process state: No such process (os error 3)`。五个 hook 的内容、事件和执行结果已经完成；失败发生在进程资源回收。

`ternilo-builtins` 通过 `/proc/*/stat` 观察进程组。已处理枚举后路径消失的 `ENOENT`，但文件打开后进程退出也可能使读取返回 `ESRCH`。该状态表示进程已经退出，应与路径消失一样跳过，继续观察进程组，而不是把正常清理记为错误。权限和其他 I/O 错误仍正常返回；没有跳过资源回收。

增加 Linux 实际进程组的并发退出回归：四个并发任务共创建并回收 32 个短命令，检查完整资源清理。相关模块全量回归另发现零超时流测试先等待固定 250ms、再要求首段文本已经到达，受启动调度影响。改为先等待实际首段输出，再检查流保持打开至取消，保留原有运行期与取消断言，不改生产超时规则。
