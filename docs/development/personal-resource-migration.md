# 个人资源转入团队

状态：选择性工作区迁移和项目／整机迁移的实现保存在未合入的 `wip/resource-migration-completion` 开发分支，尚未包含在默认分支或公开安装包中。阶段验收不代表资源迁移与恢复 1–5 已整体交付，后续范围见[任务清单](remaining-task-audit.md)。

个人空间不能添加其他成员。同团队管理权交接和同空间管理项目迁移保留原空间，不能替代跨空间迁移。`control_workspaces`、Edge／Cloud 会话、电脑凭据、上传游标和用量记录均使用空间身份；跨空间操作必须同时处理管理授权和执行绑定。

选择性迁移将指定工作区及其全部会话转入已有团队，保留其他个人资源。独立项目和整台电脑的迁移必须明确选择，不能通过改变整个个人空间的类型或隐式移动关联资源代替。文件、存储与执行身份迁移，以及跨主机接管和故障转移，是另外的实施阶段。

只有原资源所有者可以发起，目标团队角色必须允许接收。预览显示范围与共享影响，提交时复核原状态；同名冲突和过期请求须完整回滚。保留原文件、会话历史、作者、历史计量和原执行身份。旧入口、团队列表、权限组和 Live 更新一致，电脑重连后继续工作；拒绝越权、只读成员和其他个人空间资源。

验收使用合成数据覆盖 SQLite、受限 PostgreSQL、真实桌面／手机浏览器、Node 重连与旧数据升级。开发分支的冻结清单、持久回执、原子提交／中止及整批恢复需要与公开入口一起完成最终验收，再纳入正式发行。
