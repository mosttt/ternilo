# Server 网页首次设置

本轮将普通 `serve` 作为首次部署和后续运行的共同入口。配置不存在时提供不依赖业务数据库的网页，初始化 Key 从本次启动日志取得。Key 校验先于数据库访问，设置页选择 SQLite 或 PostgreSQL、保存私有配置并创建管理员。正常运行不接受管理员账号参数，不因重启重建身份。

显式终端设置命令为 `setup`，不保留旧命令别名。交互式隐藏输入与一次性自动化参数均可使用。部署目录辅助工具的 `init` 是准备部署目录的独立动作，内部调用 Server `setup`。

文档覆盖原生二进制、默认 SQLite、服务器外部 PostgreSQL、Compose 内置 PostgreSQL，以及宿主机／容器／其他主机网关位置。数据库示例区分 PostgreSQL 管理员、schema owner 和受限运行身份，并发布独立 Compose 叠加配置及初始化 SQL。默认流程不再要求单独初始化容器或指定 localhost 链接。

正常网页只读取认证配置中的实例状态，配置文件读取与数据库连接留在进程启动阶段。未完成账号设置时重启输出新的 Key；完成后以数据库所有者记录关闭设置入口。CLI > 环境变量 > 配置 > 默认值，运行覆盖不回写文件。
