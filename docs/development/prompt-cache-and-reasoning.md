# 提示前缀缓存与推理强度

2026-10-12。系统提示继续按确定顺序组装，并将会话身份移到稳定指令之后。Agent loop 增加默认关闭的 `prompt_cache`：Anthropic Messages 请求将稳定系统提示标记为 ephemeral 缓存块，会话身份及工具发现信息保留在后续块；其他协议保持原请求行为。未启用时新增请求字段不序列化，旧请求继续可读取。实际缓存命中及计费依赖上游返回，不推断固定节省比例。

`observe_reasoning` 同样默认关闭。开启后每次主模型步骤记录当前轮输入字符数、工具调用数和工具错误数，并给出低、中、高建议。超过 1500 字符、至少 8 次工具调用或存在工具错误时建议高；超过 240 字符或发生工具调用时建议中，其他为低。这是可评估的确定性观察规则，不改变模型、权限、额度或实际推理配置，也不保证目标模型支持建议档位。

观察事件持久保存，聊天过程面板提供中英韩的建议与依据。窄屏 Team 标签改为两行，只读用户也保留可见的 Team 入口。

两项提示缓存及一项推理观察 Rust 合同通过，覆盖缓存开关、静态前缀与身份分离、原文本完整保留、其他协议和实际推理参数不变、旧请求兼容及当前轮错误隔离。8 个受影响包的全目标 Clippy、63 项聊天／设置／工具栏前端测试、类型及三语检查通过；三个执行程序构建通过。Local 中英韩浏览器验证开启、保存、观察记录展示与手机布局；Server＋Node、Server＋Worker 验证观察事件保存，角色模型实际 low 推理参数保持独立。最终两项组合浏览器合同通过，页面、控制台及 HTTP 错误为空。


## 2026-10-15：可选实际推理控制

Agent loop 增加默认关闭的 `automatic_reasoning`。每次主模型请求可携带统一档位建议，执行模型调用的宿主选择实际参数，响应和持久观察事件带回选择结果。现有观察开关和旧事件保持兼容；新字段未启用时不序列化，辅助请求不携带建议。

沿用本轮长度／工具调用／错误的确定性建议。可用档位取已接受模型元数据与当前宿主映射的交集，并以手动选择及高档为上限；原生预算参数还需符合当前输出上限。不调用未配置档位、不切换模型、不改写保存设置。Server 和来源电脑各自核对可信配置，不接受请求端扩大的映射。没有自动档位的模型保留原参数，并在界面说明。

Protocol 40 项测试通过；Builtins 定向过滤运行 7 项通过，其中 2 项直接验证五种协议实际 HTTP 参数、默认关闭行为及原生预算不可用时保留旧请求。真实来源电脑转发合同通过，证明请求端修改的档位映射不会被直接采用。六个相关包全目标 Clippy，以及 Control／Cloud／Transport／Transport Store 全目标调用者检查通过。

最终本机三语浏览器 46.23 秒、Server＋Node／Worker 浏览器 44.18 秒通过：实际请求按低→中→高切换，新任务不继承旧轮错误；手动低档将三个请求均限制为低。配置保存、刷新后的实际选择记录以及 320px 页面中卡片完整可读通过，页面、控制台与 HTTP 无非预期错误。前端类型、三语、构建及匹配执行程序构建通过；截图已逐项检查。数值见[本阶段验收](benchmarks/2026-10-15/automatic-reasoning.json)。
