# 工作台性能、手动目标与实例目录

状态：2026-10-01 新阶段源码及受影响离线验证已完成，尚未发布。功能优先，Claude 官方模型列表排查按用户要求后移。配置目录不保留旧默认路径兼容，也不增加迁移流程。Work 保留设计，不发布不存在的程序。

## 按电脑分组与在线资源按需加载

侧边栏默认 computer 分组，可切换 workspace 或 flat。电脑组折叠状态按账号与空间保存，自动展开当前会话所在电脑，排序只调整本组资源，不改变物理绑定。在线电脑开关仅在电脑分组中生效。

开关贯穿初始 `/state`、Live WebSocket、搜索和归档。Server 根据当前租约和原 Node 凭据确定在线电脑，Control 在 SQL 中过滤工作区／会话，读取之前排除离线元信息；Cloud 资源保留。开启后的冷启动不下载离线数据，关闭后重新请求全部可见资源。筛选切换清理旧 HTTP／Live 代号，拒绝迟到旧范围结果。

HTTP 验证包含一个 JSON 合法但无法解析为 EdgeSessionMetadata 的离线记录：在线范围读取成功，证明没有读取后才隐藏。还覆盖重新显示全部。源码不在浏览器增加后台全量状态轮询。

## 会话切换与历史

原策略每次选择会话都清空事件、串行读取初始多页，最终才显示并订阅 Live。新策略在首个页抵达时显示并开始增量订阅，其他页后台合并。读取预算仍基于底层事件，不是 token 或对话数量；到达预算时若最早轮次缺少 turn_started，则继续补齐到该轮开头。单轮大量思考分片不再迫使用户逐页补齐。

当前账号与空间内保留最近会话的内存缓存，最多 8 项、总计 30,000 条事件及估算 24 MiB 序列化字符存储预算；缓存实际对象内存会有额外开销。切回时恢复历史、元信息和分页游标，按最后原始序号补 Live。缓存不写 localStorage 或 IndexedDB；换账号、空间、筛选范围和退出登录时清理。撤权／不可读错误清空当前正文和元信息。重建基线、重试、较早页与迟到请求继续遵守 generation 和 history revision。

纯 assistant_message_delta / assistant_reasoning_delta 每 100 ms 合并一次 UI 更新，不减少原始事件。完成回答、工具与元信息到达时先冲刷片段；切换目标清理待处理定时器，未显示片段由后续游标补读，不能漏入另一会话。

## 目标必须手动启用

工具目录及 Code Mode 默认不公开 update_goal；Tools registry 和 Planning handler 也拒绝未授权执行。真正的 `/goal` CommandStarted/Finished 记录启用目标，纯模型 GoalUpdated 不成为启用依据。目标完成或阻塞后不允许模型自行重启；用户显式 edit／resume／complete／blocked 保留正常直接命令行为。计划与 todo 不受影响。

不依赖网络的真实 Harness／模型替身验证覆盖：普通聊天模型强制尝试创建目标被拒绝；用户设置目标后模型可以完成；完成后不能自行开启新目标。

## 停止并发送全部

原 Node／本机调用在取消后同步等 FIFO driver 和 turn gate，HTTP 响应被旧任务收尾拖住。现在先保存暂停与 restart_requested 意图、发出取消信号并返回，后台等待旧 driver 和 turn gate 释放后才消费队列。Inbox document 为版本 2。进程重开恢复已接受的意图，普通停止／错误清除意图，后到的停止优先于后台重启，不重放未知工具副作用。

新提交在重启收尾期间仍保持队列暂停；重复请求合并在同一持久意图。错误继续写入队列状态，页面通过 Live 读取实际执行状态。可选 Cloud Worker 仍沿用确认退出后恢复的路径，最长等待 30 秒，不声称其快速确认已实现。

验证人为持有旧 driver 和 turn gate，要求请求在锁释放前确认，文件操作只能在释放后发生；同时覆盖意图持久重开和后续停止取消。队列按钮显示即时等待反馈，长流式思考减少同步重复渲染。

## 实例目录

本机分类为 config、secrets、data、cache、runtime，serve 根配置统一 config.json。本机配置首次私有原子发布，后续 CLI／env 只覆盖本次启动；相对 Profile 基于实例目录。Server／Worker 使用 --config-dir 和对应 CONFIG_DIR 环境变量选择目录，内部固定读取 config.json；Worker 不再保留第二套目录参数。Server 默认 SQLite 位于 data/db/server.sqlite3，Docker 总配置和 WorkerPolicy 路径同步调整。可选 Worker 使用 config.json 和 data/workspaces；部署备份／恢复与对应测试同步更新。Work 只落实目录及持久卷的设计约束。

正式说明见[配置目录](../zh-CN/data-layout.md)、[工作台使用](../zh-CN/user-guide.md)和[目标行为](../zh-CN/agents.md)。运行中的实例未自动移动或替换。临时构建与浏览器产物位于独立目录，不覆盖在线实例的 target/debug 或根 dist。
