# 空白会话管理与默认复用

2026-10-11：用户确认默认复用可用空白会话，同时保留显式另建；不设置只能一个的硬性上限。本项已实现并完成本地验收，尚未发行；随后继续剩余任务 1–5 及既定顺序，排除 Work。

## 实施

原侧栏菜单通过 `!session.blank` 隐藏所有空白会话操作，空白聊天页也没有顶部菜单，导致已存在的删除接口无法从界面使用。现在空白行可重命名、归档，所有者可通过确认对话框删除；删除会话不移除工作区文件。重命名后的空白行显示实际标题。

普通新建按当前账号／空间及工作区合并正在进行的请求。候选必须属于自己、未归档、没有父会话或子代理，标题仍为占位名，权限、模式、预设及模型与本次新建匹配。复用前读取 `/state`、默认模型、预设和队列，排除草稿、附件、引用、插件覆盖、活动运行、暂停及待处理任务。预设快照不同的会话也保留。Cloud 还保留创建／更新时间检查以保护单独配置过的 token 额度。Server Node 的同步时间不作为用户修改配置的依据。

工作区菜单提供“另建会话”，始终创建独立记录。没有后台自动清理，也没有批量删除历史空白会话。删除确认说明草稿／附件影响，取消保留内容；成功后清理当前账号在此浏览器中的草稿缓存。文本沿用现有浏览器存储，附件／引用新增按账号、空间、会话隔离的内存缓存，支持会话切换，尚不支持跨网页刷新恢复。

纯触摸验收还发现 Radix 悬停卡触发器拦截 `touchstart`，在 React 的被动事件监听器内调用 `preventDefault`。侧栏行包含真正的操作按钮，现在保留原生触摸事件，桌面悬停／聚焦行为继续通过原触发器处理。

## 验证结果

- 工作台状态 41 项、侧栏行／浏览器组件 24 项、草稿 6 项单元测试通过；输入框相关既有测试也已通过。覆盖连点合并、显式另建、草稿／附件／引用／配置／队列保护、Cloud 独立 token 额度保护和所有者删除权限。
- 类型检查、i18n（279 个源文件）、正式文档（108 篇）、前端构建及匹配 CLI／Server 开发构建通过。
- 真实浏览器合同已加入 CI：独立 Local 与 Server＋Node，覆盖旧空白会话复用、另建、草稿附件保留、取消／确认删除、320×560 触摸屏按钮可达性和工作区文件保留。最终构建两项通过，分别为 7.79 秒和 15.33 秒，页面、控制台及 HTTP 错误均为空；桌面和手机整页截图已检查。
- 手机流程使用触摸打开侧栏、滑动溢出列表、打开会话菜单和确认删除，不依赖鼠标悬停。确认／取消按钮完整位于视口内且无遮挡。
- 初测发现不存在的 GET 单会话接口（405）、Server 同步时间误判和被动触摸监听器警告，均在最终验收前修正；没有通过过滤错误或放宽断言取得通过。

本轮使用隔离目录、随机端口和合成账号，未操作日常实例及真实数据。结果见[验收记录](benchmarks/2026-10-11/blank-session-lifecycle.json)。本功能随后已随 v0.2.12 公开。直接解包公开程序后，Local 与 Server＋Node 桌面／手机合同均通过；发行复测中的一次视口切换超时及完整复测结果见[发行验收](release-0.2.12-acceptance.md)。这些浏览器检查不替代所有物理手机系统验收。
