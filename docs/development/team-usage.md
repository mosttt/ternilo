# 团队用量与金额估算

2026-10-12。Agent Team 增加用量页，按实际响应中的 Provider／模型显示主代理、子代理和可读取成员合计。按父子会话树解析成员，避免不同团队同名子代理混入。会话切换取消旧读取，缺失或不可访问的成员明确标为未知。

输入、输出、缓存读取、缓存写入及推理分开展示；缓存属于输入、推理属于输出，不重复计数。原始记录中的重新生成前响应计入，回放响应不计入。没有报告用量时不推断为零费用。估算单价按每百万 Token 和币种在浏览器保存，不更改 Provider 配置，支持 USD／CNY／KRW；金额不包含辅助调用及未记录失败请求，不作为供应商账单。

上下文指示器补齐 Server Node 的账号、电脑和平台绑定模型窗口，并显示最近响应的缓存、推理明细以及测量范围说明。界面及提示有中英韩文，手机 Team 通过“更多会话操作”进入，用量页可原生触摸滚动。

25 项相关前端测试通过，包括父子映射、同名隔离、未知单价与用量、缓存计费、重放排除、切换会话后的迟到响应、Server Node 模型窗口。类型检查、285 文件三语检查、Web 与实际程序构建通过。实际浏览器验证本机中英韩、320×560 原生滚动、主子代理分组、实际 Token 数、币种隔离和单价恢复；Server＋Node、Server＋Worker 也验证对应成员及模型用量。最终两项浏览器合同通过，页面、控制台与 HTTP 错误均为空。
