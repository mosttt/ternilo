# 上下文组成展示

2026-10-15。每次主模型调用前，从已经完成上下文压缩、工具展示和历史输出预算处理的 `ModelRequest` 记录字符组成。沿用 `model_request_started` 事件，新增可选 `context_usage` 字段；旧事件不需要补写，原系统提示字段保持不变。

统计分为系统指令、工具定义、对话消息、工具结果、推理与供应商续传状态。字符串按 Unicode 字符计数，Schema、工具参数及续传块按其 JSON 字符计数；内联文本附件归入所属消息，图片和引用附件只记录未测量数量。不按字符推算 Token，供应商编码或附件展开后的变化不属于这份宿主统计。

输入框弹层分别显示最近响应的 Token 用量与最近请求的文本组成。缺少上游用量或模型窗口时仍可查看组成；最新请求没有记录时不会继续展示更早请求的组成。弹层复用现有 Radix Popover 的视口避让与滚动机制，支持中英韩及窄屏。

协议 39 项、真实模型请求 4 项、工具历史 6 项及组件 8 项测试通过；Protocol／Builtins／Local／CLI／Server／Worker 全目标 Clippy、TypeScript、三语扫描、前端及配套程序构建通过。旧事件读取、缺少窗口时的组成显示、最新请求缺少统计时清除旧值，以及不足 1% 的实际比例均已验证。

本机中英韩浏览器合同 35.54 秒、Server＋Node／Worker 合同 29.97 秒通过。合同直接对照接收端实际请求中的系统指令、工具 Schema 和预算处理后的输出；Node／Worker 读取大文件时显示的工具输出为预算后的 1024 字符。320×420 矮屏验证弹层不越界、无横向溢出，并以原生触摸滚到末项。桌面和手机截图已检查，控制台及相关 HTTP 无非预期错误，临时进程和数据已清理。结果见[阶段验收](benchmarks/2026-10-15/context-composition.json)。
