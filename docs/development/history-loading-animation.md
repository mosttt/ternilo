# 会话历史加载动画

2026-10-06：用户要求打开页面读取历史时显示加载动画。原有动画只等到首个历史页返回；长会话后续自动分页仍在读取，页面已经没有加载提示。

会话控制器现在公开本次初始历史读取状态，首个页到达后仍保留状态，直到分页完成、失败或 Live 重置历史。首屏继续使用居中加载动画；已读取内容先显示，后续自动分页与手动加载较早历史时，在会话顶部显示带旋转图标的提示。缓存会话切回直接显示，不增加固定等待、额外历史请求或轮询。首次失败沿用重试，追加失败保留已读取内容与游标。

会话控制器 29 项测试通过，包含首个页先显示、后续分页仍在加载、Live 续接不提前结束状态、分页失败和历史重置清除状态，以及缓存切换。TypeScript、国际化、100 篇正式文档检查、Web 生产构建及嵌入匹配资源的 CLI／Server 开发构建通过。

现有长历史浏览器合同已补充延迟首个页和后续页、动画实际运行、缓存切回没有加载提示、桌面／手机截图和无横向溢出的断言。本轮环境禁止监听回环端口，执行合同在 `listen 127.0.0.1` 阶段返回 `EPERM`，未进入浏览器页面。另尝试无需监听端口的 Chromium 空白页面验证，浏览器启动同样返回 `Operation not permitted`；备用浏览器代码工具被当前审批策略拒绝。完整浏览器验收尚未完成，不把此环境阻断记为测试通过或服务功能失败。
