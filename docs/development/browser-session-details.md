# 浏览器登录会话详情

用户要求登录会话显示设备、主机名、IP 与最后活动时间。浏览器不能直接读取真实主机名，因此界面明确提示不可获得；设备描述取自 User-Agent，不冒充经过验证的主机身份，也不引入地理位置查询。

原生浏览器会话新增独立 `browser_session_details` schema 组件，保留 Control 14 和现有身份／撤销检查。明细表按已有 Token 摘要关联，但公开 API 只返回既有公开会话 ID、首个浏览器标识、首次与最近来源 IP、最后活动时间。旧会话缺少明细时返回空值，后续已认证访问记录实际观察。

初始化、注册、邀请接受和登录在签发后记录信息。认证 HTTP 访问更新最后活动，通常一分钟一次，IP 变化时立即更新。该时间不是用户鼠标活动，也不将空闲 WebSocket 当成新活动。更新同时检查账号归属、有效期和撤销状态；其他账号不能用被观察账号的 Token 写入明细。

默认采用连接对端 IP。新增 Server 配置 `trusted_proxy_ips`，及 CLI／环境对应参数；只在对端可信时解释 X-Forwarded-For，从右向左剥离已知代理，在第一个未知地址停止。无效转发链回退至实际对端，缺少连接地址则保留未知；不信任任意请求头。

验证包括 SQLite 的账号隔离、撤销后不写入、首次来源保持、更新节流与 IP 变化；Server 单元测试覆盖伪造转发头、可信多跳、IPv6 和无效链；浏览器验收增加真实 IP、浏览器描述及时间断言，并继续覆盖撤销与窄屏布局。PostgreSQL 受限 runtime 账号验证通过；完整浏览器撤销、OIDC 与 320／390px 页面检查通过。
