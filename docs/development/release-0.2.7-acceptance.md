# v0.2.7 发行验收

2026-10-06：[v0.2.7](https://github.com/mosttt/ternilo/releases/tag/v0.2.7) 已公开，来源为 `166993334a854b90d1de2da40c3b5a451ad4fc3c`，固定 Linorun 为 `46cca18d63d1bef1c5475ac6912f18f5426a115b`。[完整发行流程](https://github.com/mosttt/ternilo/actions/runs/37331709293)和[主分支完整检查](https://github.com/mosttt/ternilo/actions/runs/37331703669)通过。

本轮包含上游邮箱直接使用、上游用户名自动注册与回退、邀请／审核／人机验证约束、手机电脑操作单列、Turnstile 旧回调隔离与错误码显示。功能与本地验收见[注册资料](oidc-registration-profile.md)和[验证组件](turnstile-mobile-lifecycle.md)。双语正式文档与发行说明已同步。

完整前端检查通过：156 个单元文件、1004 项测试、7 项富文本测试、类型、国际化及生产构建。Server／控制库全目标 Clippy、控制库 3 项认证测试通过。实际 Server 的六项浏览器合同通过：多提供方、标准 OIDC、自动及回退资料、平台用户名、手机电脑管理、Turnstile／OAuth 配置。实际页面与控制台、权限拒绝及网络检查通过，手机电脑管理与用户名回退截图已复核。

首次新资料合同在手机侧栏关闭时点击退出，调整为先打开真实侧栏；随后界面增量更新后发现测试程序嵌入旧资产，重新编译匹配程序后通过。较早用户名合同原本预期邀请模式关闭外部新用户表单，与现有 OAuth 邀请功能不符；改为检查邀请输入、未给邀请拒绝 403、不创建账号，并显式切换账号后检查原身份。测试未放宽后端权限或把旧资产当成新版本。

发行前真实 Cloudflare SDK 测试 Key 发现额外的 grid 最小宽度问题，已取消未公开的初次构建，收回临时标签。容器宽度修复后，实际官方 SDK 在安卓 Edge User-Agent 的 Chromium 页面通过宽／窄／主题切换、单 iframe、可用按钮及无页面错误检查；生产构建、匹配 Server 和带 300px 固有最小宽度的 SDK 浏览器合同也通过。只使用公开测试 Key，没有把本机联网验证作为通用 CI 要求，详见[组件记录](turnstile-mobile-lifecycle.md)。

额外试跑了未列入当前 CI 的历史 `control-node-browser-e2e` 合同。其表单／成员名称／原生 select 断言已经过时；临时校正后可完成新用户注册、成员管理、电脑连接和工作区创建，但后续依赖当前未提供的 `/write` 命令而失败。临时测试调整已撤回，不把此历史合同记为通过；本轮 OIDC、手机电脑管理、生命周期及现行发行门禁分别作为验收证据。

最终发行检查又发现 Linux 读取 `/proc/*/stat` 时进程已退出的 `ESRCH` 被误当成资源清理失败。已修正并补充实际短进程组回归；Builtins 163 项、本地内核 219 项测试及三个相关模块全目标 Clippy 通过。流测试改为收到首段输出后观察无超时和取消行为，避免把启动调度当作模型超时规则。说明和本机 SIGKILL 验证边界见[进程清理记录](process-cleanup-exit-race.md)。官方失败测试 Key 的真实 `600010` 提示与手动重试也通过。

主分支首轮撤权合同在侧栏已经移除、聊天视图尚未清空的瞬间取样失败；同一来源的完整发行检查及主分支第二次检查均在原断言下通过。补充测试同步等待聊天视图实际清空，仍要求零条内容、七次实际读取拒绝及无后续事件；该同步修正在主分支验收后提交，不移动已经公开的版本标签。

42 项公开附件全部下载，实际长度、SHA256、GitHub 摘要和清单一致。12 个程序归档覆盖六个平台，程序集合、ELF／PE／Mach-O 架构、96 份双语正式文档和最新版 README 字节核对通过；不包含开发记录和私有配置。九个安装器的实际摘要和文件格式通过。一次归档下载发生 SSL EOF，重取后通过完整长度和摘要，未把不完整文件记为成功。

公开 Linux `ternilo`／`ternilo-server` 均为 0.2.7，八项实际程序浏览器／传输合同通过：多提供方、标准 OIDC、自动及回退资料、登录与 Turnstile 设置、平台用户名、手机电脑管理、共享撤权与暂停恢复，以及真实 WSS／未信任证书拒绝。手机截图已检查，按钮各占一行；上游邮箱不提供编辑框。

空 Docker 配置的匿名拉取通过，版本、来源和许可标签正确。`latest` 与 `0.2.7` 的完整双架构索引相同，摘要为 `sha256:53bbe999c2ff2742bf57cadba6e627b9e7be4a111459824208097f91d7696b5f`；AMD64 为 `sha256:24c11a13c2b37ea0f92f9ea745a740f1a1764395d74ecb9f2d3a15068725b769`，ARM64 为 `sha256:d1481542f62ad878025ba81320343cbdf73c6ecedb192724d41faab00201b04b`。

公开 SQLite Compose 和 PostgreSQL overlay 均通过真实手机浏览器的初始化 Key、数据库选择、创建管理员、默认英文／手动中文覆盖、登录及 down/up 身份和配置持久化验收。Server UID 为 10001、根文件系统只读；PostgreSQL 使用独立 schema-owner 和受限 runtime，无数据库主机端口。核心页面、控制台与 HTTP 流程无错误。两个测试项目及其容器、网络、私有卷已经清理，未操作已有实例；本机独立网段覆盖只保留在临时验证目录。

生产小米安卓 Edge 的 Cloudflare 挑战最终结果仍需用户更新后复测；官方测试 Key 证明接入、宽度、生命周期和错误回调处理，不代替生产风控结果。Desktop 签名、公证、自动更新与全部物理设备的安装／卸载验收仍不在本版已完成范围。
