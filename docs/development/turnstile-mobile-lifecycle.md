# 手机 Turnstile 生命周期与错误诊断

2026-10-05：用户在 Chrome 手机模拟和真实小米安卓 Edge 上遇到验证失败，桌面控制台显示 600010，手机组件同时显示成功／失败。只读公网核查确认 CSP 已允许 Cloudflare 脚本与 iframe。官方错误表将 600* 归为挑战失败；源码中尺寸／主题重建后旧组件回调仍可清除新组件 token，属于可复现的接入缺陷，但未据此宣称已找到生产风控拒绝的唯一原因。

组件现在用每次渲染的序号隔离回调，成功／过期／失败／超时均只处理当前实例。按照 Cloudflare 配置，取消 SDK 自动重试和自动过期刷新，由界面重试统一重建；错误回调返回已处理，并显示真实错误码。旧组件成功不能恢复过期身份，旧组件失败也不能覆盖已完成的新验证。服务端 Siteverify、域名及 action 校验保持执行，没有绕过验证或关闭生产防护。

真实浏览器使用独立测试实例与模拟 SDK，验证 compact→flexible、主题、旧失败／过期／成功回调、当前失败、600010 显示及手动重试。直接不带验证令牌的真实后端密码请求继续返回 403。此合同证明接入生命周期修正，不能代替用户真实手机与生产 Cloudflare 的再次验收；没有填写用户凭据或尝试解决生产验证挑战。

发行前追加 Cloudflare 官方测试 Key 的真实 SDK 检查，发现 flexible 组件的 300px 最小宽度会撑大未约束的 grid 子元素。窗口从 430px 缩到 320px 时，可用容器只有 238px，测量子元素仍为 300px，未能进入 compact 模式。容器增加 `min-w-0 w-full`，按实际可用宽度测量；浏览器合同补充带相同固有最小宽度的 SDK 替身和宽→窄→宽检查。

修复后真实官方 SDK 在安卓 Edge User-Agent 的 Chromium 页面通过 430px→320px、主题切换、320px→430px：每次仅有一个 iframe，窄屏组件为 150×140px，宽屏为 348×65px，登录按钮可用且无页面错误。只使用官方公开的测试 sitekey，未提交真实登录或生产挑战。证据保留在本机临时目录，不把本机网络依赖加入正式 CI。初次检查误以为 iframe 位于普通 DOM；SDK 使用封闭 Shadow DOM，调整为通过浏览器 frame API 读取，没有修改 SDK。尚未公开的发行构建已取消，原临时标签收回，补充验收完成后生成最终标签；已公开 v0.2.6 保持不变。

官方失败测试 Key 进一步验证真实 `600010` 回调：页面显示实际错误码，登录按钮禁用，点击重新验证后更换唯一 iframe 并再次正确显示失败。测试 Key 明确要求失败，该结果验证错误与重试处理，不代表生产挑战被提供方接受。
