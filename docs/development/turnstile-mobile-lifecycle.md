# 手机 Turnstile 生命周期与错误诊断

2026-10-05：用户在 Chrome 手机模拟和真实小米安卓 Edge 上遇到验证失败，桌面控制台显示 600010，手机组件同时显示成功／失败。只读公网核查确认 CSP 已允许 Cloudflare 脚本与 iframe。官方错误表将 600* 归为挑战失败；源码中尺寸／主题重建后旧组件回调仍可清除新组件 token，属于可复现的接入缺陷，但未据此宣称已找到生产风控拒绝的唯一原因。

组件现在用每次渲染的序号隔离回调，成功／过期／失败／超时均只处理当前实例。按照 Cloudflare 配置，取消 SDK 自动重试和自动过期刷新，由界面重试统一重建；错误回调返回已处理，并显示真实错误码。旧组件成功不能恢复过期身份，旧组件失败也不能覆盖已完成的新验证。服务端 Siteverify、域名及 action 校验保持执行，没有绕过验证或关闭生产防护。

真实浏览器使用独立测试实例与模拟 SDK，验证 compact→flexible、主题、旧失败／过期／成功回调、当前失败、600010 显示及手动重试。直接不带验证令牌的真实后端密码请求继续返回 403。此合同证明接入生命周期修正，不能代替用户真实手机与生产 Cloudflare 的再次验收；没有填写用户凭据或尝试解决生产验证挑战。
