# 项目记忆、仓库工具与文档交付

2026-10-12。项目记忆、Git／GitHub 专用工具和文档实际渲染使用独立内置插件，沿用现有能力、权限、持久事件和附件通路。配置及文档检查卡支持中英韩文。`ternilo-work` 继续只保留框架。

项目记忆存放在工作区根目录 `.ternilo-memory.json`，按条目记录长期项目事实，和会话历史检索分别使用。读操作不创建文件；写操作要求工作区写权限，并用版本号、文件锁及临时文件替换避免静默覆盖。旧版本写入会失败，调用方应先重读再决定如何合并。默认最多 64 条、每条 4096 字符。

Git 工具将查看状态／差异／日志和限定路径提交分开。提交先明确路径，再使用 `commit --only`；其他暂存内容保留。参数按独立 shell 参数引用。GitHub 使用原生 HTTP API，提供 PR 列表、差异与检查读取、草稿创建和指定 head SHA 的合并。分页结果带完整性标记；复核期间 head 变化会拒绝结果，HTTP 成功但 `merged:false` 仍是工具错误。发布需要执行端可用的凭据引用及已有授权流程，凭据不会因插件启用而自动转发到 Worker。当前 Worker 的 namespace 禁止外网，GitHub 工具在该环境明确返回限制；HTTP 客户端不在插件激活期创建，避免隔离环境缺少系统证书时拖住整个能力图。文档浏览器也必须在隔离环境内部可用，不扩大 Worker 的系统挂载和网络权限。

文档渲染读取 Markdown 或静态 HTML，在执行端调用已配置的 Chrome／Chromium，通过实际浏览器检查横向溢出、缺失图片和未内嵌资源，生成持久 PNG 附件。源文件最多 512 KiB、截图最多 8 页；页面脚本和外部资源被禁用。截图进入后续模型上下文及会话卡片，模型应逐页查看后记录检查结论。结论必须对应同一路径最新渲染且源内容哈希仍一致；自动检查发现问题时不允许记录通过。渲染完成只表示等待检查，不能等同交付通过。

Local 浏览器合同已通过：记忆跨会话及重启持久、过期 revision 拒绝、只读不能通过审批升级写入、无关暂存文件保留、GitHub 草稿／分页／head 变化／合并返回检查、溢出文档修正重渲染、旧截图不能验收、截图进入真实模型请求、附件重启后可读，以及中英韩和 320px 页面布局。全部 GitHub 发布测试只调用本地合成服务。专用 Git Rust 测试通过，包含带 shell 特殊字符的真实文件名。

Server Node／Worker 浏览器合同已通过：记忆跨执行进程保存、Git 限定提交、Node GitHub 读取、隔离 Worker 的网络限制、Worker 隔离环境内真实渲染和修正、截图同步 Server 后关闭 Worker 仍可读取，页面／控制台／HTTP 错误为空。执行端截图已纳入附件镜像与恢复清单。测试只在临时工作区内准备浏览器，不增加生产环境的挂载或网络权限。

综合验证发现并修复文件锁释放问题：并发启动子进程时，继承的文件描述可能令仅关闭句柄的锁延迟释放，更新结束现在明确解锁。173 项 Builtins、38 项 Protocol 单元测试通过，Worker 附件引用合同及全目标 Clippy 通过。前端 1039 项单元测试、7 项富文本测试、类型检查、三语和正式文档检查通过。最终匹配构建及发版验收仍待收尾。


## 2026-10-15：发布状态与文档公式
