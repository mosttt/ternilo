# OIDC 账号信息与移动端电脑操作

2026-10-05：用户确认登录设置故障恢复，随后指出 OIDC 首次注册重复要求邮箱。当前 Server 已校验 ID Token 和 UserInfo，但没有把个人资料传给注册页。按用户最终选择，上游提供邮箱时直接使用，不能编辑或通过注册请求替换；同时采用 `preferred_username`／`username`，可用时自动注册，重名或不符合平台格式时再选择。未返回邮箱时补填联系邮箱；邀请、审核与 Turnstile 保持各自检查，不按邮箱合并身份。

邮箱和用户名来自校验后的 ID Token／匹配 sub 的 UserInfo；浏览器只在当前标签页保存资料，切换账号和退出清除。认证数据的数据库格式、账号身份和主密钥保持不变。本阶段同时将手机电脑管理卡片操作改为一行一个按钮，保持完整文字与点击面积。

实现与验收完成：完整前端 1004 项单元、类型／国际化／构建、相关 Rust Clippy 和认证测试通过。实际程序通过多提供方、标准 OIDC、自动／回退注册、客户端邮箱改写忽略、邀请／审核、用户名规范、手机电脑管理和 Turnstile 生命周期的真实浏览器合同。移动端截图已检查。较早用户名合同按当前邀请注册规则更新，仍检查无邀请返回 403 且无新账号；没有放宽权限检查。v0.2.7 已公开并完成公开程序和两种数据库部署验收，见[发行记录](release-0.2.7-acceptance.md)。
