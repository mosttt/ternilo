# v0.2.21 发行验收

沿用已验收的客户端远程升级和电脑下拉选择。v0.2.20 标签保留，但该候选因 320×560 短屏侧栏缺陷而未公开；不让同一标签对应不同源码。资源迁移 WIP 与 Work 继续排除。

短屏修复为工作区区域保留最小可用高度，底部空间与管理导航在剩余高度内独立滚动，不缩小文字或触摸按钮。已有空白会话浏览器用例同时验证会话列表至少 100px、触摸滚动与删除，并补充底部导航触摸滚动后进入用户设置。

本地已使用当前 Web 资源完成 Local 与 Server／Node 两项真实浏览器回归，均通过；短屏会话列表可触摸滚动、删除，底部导航可滑动并打开设置，页面、控制台与网络错误为空。实际检查了 320×560 的修复前后截图。TypeScript 检查通过。

工作区、Desktop、lockfile、Compose、正式打包示例与中英文发行说明统一到 0.2.21；远程更新策略的首个客户端版本和 Server 版本范围下限也改为 0.2.21。首次升级仍需成套手动升级 Server 与接入端到 Executor 协议 49。

本轮先完成候选完整检查，再创建正式标签，由现有 Release 流水线执行打包、镜像验收、签名与公开发布。生产私钥只由受保护发行环境使用，本机不读取；不替换或重启用户部署。

短屏候选 `814b8ed` 的 [完整 Checks](https://github.com/mosttt/ternilo/actions/runs/39777689622) 已全部通过，包括浏览器、原生桌面、恢复与四个平台检查。

客户端和 Server 的“关于与诊断”均显示运行版本。版本由各自程序的编译版本注入启动数据，Server 不使用所选 Node 的插件目录修订；无工作区也可查看。中英韩文案已同步，两端真实浏览器逐一核对页面版本与所运行程序的 `--version`，包含手机布局，共 2 项通过；控制台、页面与网络错误为空，实际截图已检查。About 组件 3 项、类型与三语门禁通过。

最终候选 `0b1ba35` 的 [完整 Checks](https://github.com/mosttt/ternilo/actions/runs/39788793625) 通过并经 PR #11 合并。随后 [正式 Release](https://github.com/mosttt/ternilo/actions/runs/39796304238) 在 PostgreSQL Node 浏览器用例中发现取消事务启动时的连接污染；稳定最小复现得到相同的只读事务写入错误。发行已取消，未签名或公开 v0.2.21，原标签不移动。修复与后续发行见 [v0.2.22 验收](release-0.2.22-acceptance.md)。
