# v0.2.25 发行验收

2026-10-24：用户确认验证通过后发布 v0.2.25。基于已公开 v0.2.24 与验收记录提交 `bb819b5`，修补提交为 `b20c86f`。范围为远程升级慢启动、无法确认完成的旧执行资源、服务管理器提前校验及当前版本与最近操作结果的区分；具体现场分析见[远程客户端更新](remote-client-updates.md)。

## 修复与验证

旧更新器的本机健康检查约为 30 秒。用户新版可正常启动但需要几十秒；独立 Supervisor 场景使用官方 0.2.23／0.2.24 包与官方签名清单，正常升级约 6 秒完成，延迟新版启动 45 秒后于约 33 秒回退，复现现场错误。修正后的更新辅助程序在相同延迟下完成安装、健康检查和重连，并释放操作锁；不重建或替换官方归档，不使用生产私钥。

未知资源回归在修复前得到普通忙碌等待状态；修复后三个维护门回归及账号撤销的未知进程状态回归通过。新增实际延迟 35 秒才注册健康服务的测试通过（35.25 秒），确认超过原窗口仍能正常完成就绪检查。更新窗口九项测试、类型检查、i18n、受影响 all-targets Clippy、Client／Server 构建和文档检查通过。

实际浏览器验证当前内嵌 Web，使用三类更新状态夹具覆盖旧资源、错误服务名、新版已运行但旧流程失败；三语言、390×600 深色页面、直接可见的处理提示、诊断展开和可见操作按钮均通过，没有页面、控制台或 HTTP 意外错误，截图已检查。首次验证因两个同名关闭按钮导致定位不唯一，已定位实际底部操作按钮，未放宽产品断言。

当前服务已升级且在线的用户电脑保持运行，不通过删除状态或停止服务来掩盖旧操作错误。慢启动电脑获取本次修补时建议手动安装，因为旧客户端仍执行旧更新器；不修改 v0.2.24 的标签或公开产物。
