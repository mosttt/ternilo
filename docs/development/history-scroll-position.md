# 历史补齐时保持阅读位置

2026-10-12。旧历史按页插入对话时，已显示的内容会向后移动；用量统计稍晚显示也会增高输入区。原有实时输出跟随逻辑不会在已结束的对话中修正这些变化。浏览器延迟每批历史响应后，修复前第一批即可让触底位置离开底部 326px，另可观察到统计栏新增造成的 24px 位移。

历史插入和统计首次显示前读取 DOM 位置，完成同一次提交后恢复：停在底部时保持底部，主动上滑时按消息序号及可见段落保持阅读位置。保留像素舍入余量，避免多批插入累计漂移。恢复不启用实时跟随，也不覆盖切换会话／视图时已有的位置恢复。

历史插入时的轮次显示窗口在提交 DOM 前调整，保留原来的末尾；超过 320 轮时仍保留最新内容。手动请求更早历史时，使用响应到达前的阅读位置，避免恢复成点击按钮时的过期位置。已加载轮次的本地翻页仍使用原来的翻页锚点。

新增浏览器合同覆盖六批历史、长单轮多步骤以及 450 轮历史，在 1280、390、320px 分别验证触底和段落阅读共 12 个场景，检查控制台、页面和网络错误。开发浏览器和打包程序合同均已通过，位置误差小于 2px；47 项相关状态、轮次与滚动单元测试通过，随后前端全量 160 个文件、1039 项测试及 7 项富文本测试也通过。匹配构建后的 6 项既有浏览器回归全部通过，覆盖 Local 鼠标／触摸手势、主动回到底部、缩放和会话切换恢复、Server 账号／平台模型在三种宽度的发送与跟随、30005 条事件的完整加载、缓存切换、Local／Server 重连及离线有界历史。页面、控制台及相关 HTTP 错误为空。
