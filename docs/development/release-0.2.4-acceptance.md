# v0.2.4 发行验收

本版包括多提供方 OAuth2／OIDC、OAuth2-only 开放及邀请注册、账号状态标签、Rustls WSS 初始化修复，以及稳定版镜像 `latest` 别名。

本地验证已通过 999 项 Web 单元、类型检查、国际化、正式文档检查、相关模块全目标 Clippy、SQLite 7 项注册合同、13 项 Server 管理 API 回归、PostgreSQL 18 场景身份合同和四项受限角色的 OIDC／浏览器会话／MFA 集成用例。

实际浏览器覆盖两个具名提供方、独立身份、不透明上游令牌、OAuth-only 密码接口拒绝、改名保持会话、停用拒绝、跨跳转邀请及重启恢复；既有 OIDC 无效声明、PKCE、绑定、刷新重放、MFA、Turnstile 和地址恢复合同通过。浅深主题与 320px 手机截图已检查。旧发行程序的 WSS panic 在真实 TLS 握手中复现，修复程序拒绝不可信证书并保持运行。

v0.2.3 的 `latest` 别名已通过工作流及匿名拉取验证。本版的完整 CI、公开安装包、镜像及新别名等待发行流程完成后核对，不将当前源码验证当作公开产物验收。
