# 侧栏电脑下拉选择

2026-10-21：按用户确认，将“按电脑”视图改为下拉选择，不使用横向标签。下拉框位于工作区工具栏下方，包含“全部电脑”和当前空间内可见的各执行位置；各电脑显示在线／离线状态。首次沿用全部显示，避免升级后隐藏原有列表。

选中单台电脑时，列表直接呈现其工作区和会话，去掉重复的电脑标题和一层缩进；选“全部电脑”恢复原分组、折叠和未分组历史。选择按账号与空间保存在浏览器，折叠状态继续使用原机制，当前页面内保留各视图的滚动位置。电脑下拉选择只过滤已有侧栏数据，不切换当前对话，不改变执行位置、权限、历史缓存或后端加载范围。

搜索仍覆盖当前空间的全部可见电脑，打开结果后定位到对应电脑。原“只显示在线电脑”的后端按需加载、搜索和归档范围保持；此开关启用后，电脑下拉框也只列出已加载的执行位置。已选电脑不再出现在可见数据中时显示其余电脑，不留下空白筛选。按工作区和单列表视图不受电脑选择限制。

复用现有 `ChoiceSelect`，支持键盘选择、Escape 关闭、长列表滚动和窄屏布局。新增文案提供中文、英文与韩文。

验证完成：受影响侧栏、工作区行和偏好解析测试 39 项通过；TypeScript、i18n、正式文档检查及 Web 构建通过。独立 Server／双 Node 配合当前 Web 资源的真实 Chrome 流程在 27.61 秒内通过：单台／全部切换不改变当前会话、刷新恢复选择、搜索跨电脑定位、在线范围冷加载及 Live、18 个工作区的纵向滚动与切回恢复、中文／英文／韩文下拉内容、键盘打开与 Escape 焦点返回、390px 深色手机布局。控制台、页面和 HTTP 错误断言通过；已检查实际中韩下拉及深色手机截图。

本改动完成于 `feat/sidebar-computer-picker`，已整合到 v0.2.23 发行候选，与独立完成的远程升级一同发布；状态见[发行验收](release-0.2.23-acceptance.md)。
