## ID 与名称模型的后续调整

用户进一步提出：电脑 ID 改为系统生成、唯一且不可修改的内部追踪标识；原来手工填写的 ID 改为可修改且唯一的电脑名称。普通列表、分组、工作区位置和会话标题下的机器信息均展示名称，详情单独显示 ID。当前这一步尚未实现，不能把本轮可选显示名称功能称为已经完成系统 ID／名称分离。

名称建议在同一账号、同一空间内唯一；ID 用于资源引用、路由、缓存和审计。重连必须使用持久保存的原 ID 与凭据，不重新登记，也不靠同名、IP 或主机名认领。名称修改不改变引用。身份表示登记的 Ternilo 实例：同机多个独立实例使用各自的 ID、凭据和目录。

断网、程序重启和电脑 IP 变化应保持同一身份。数据目录或凭据丢失时必须区分“恢复原登记”和“登记新实例”；恢复须由原归属账号授权并核验持久绑定，不能因同名自动合并。复制配置或恢复备份不能在两台运行中的实例间同时复用一个身份。

按新模型，吊销保留原身份和可见登记；移除从登记列表隐藏，但有历史引用的内部身份仍保留。后续应增加明确的“恢复此电脑接入”，沿用原 ID。与“登记新电脑”区分；本轮尚未提供该恢复入口，凭据轮换继续后移。
