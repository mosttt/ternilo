# 设备 Provider 用量

[English](../en/device-provider-usage.md)

在 Server 的“我的模型 → 用量”选择“设备本地”，再选择空间、自己的电脑与 UTC 月份。列表展示已同步的 Provider 调用尝试，支持按 Provider／模型搜索和向后翻页。上方汇总覆盖整月符合搜索条件的全部已同步原始记录，包含未翻到的分页；它仍是设备报告，不是上游账单。

一轮任务可能产生多次模型调用、重试及标题等辅助调用，每次实际尝试分别记录。输入、输出、缓存读取／写入和推理 token 保留上游协议语义，未报告的字段显示“未报告”，明确报告的零显示零。只保存开始而没有完成的尝试保持未完成，不能据此认定上游没有消耗。调用者来自原始任务：本机用户、自动化，或通过 Server 验证的账号；无法验证的账号声明不显示为可信身份。

这是设备报告。Server 自身代理的模型请求仍使用独立账本和预算；官方“连接 Server”模型及托管 gateway 不再生成设备直连记录。“全部 Server 来源”只汇总 Server 账本。手动把自定义 Provider 地址指向 Server 时，两侧各有自己的来源记录，也不会将设备报告再次扣入平台预算。

设备必须通过远程控制登记到 Server，使用匹配的执行器协议 `48`。仅授权模型访问的客户端不会因此上传会话或取得电脑访问权。Server 离线时记录留在电脑日志中，重连后沿既有事件同步补传；同一记录重放不会新增尝试，分叉复制的历史也不会被当作新调用。未升级前的旧调用、未同步部分、仅存在其他电脑上的记录不在此页覆盖范围，空列表不代表没有调用。

只有电脑所有者可以读取整机报告，共享会话成员和空间管理员不会仅因共享或管理角色获得这一权限。记录包含公开会话位置、Provider／模型／协议、尝试状态和上游 request ID，不包含提示词、凭据、原始响应或上游错误正文。它依赖当前保留的原始日志和 Server 会话映射；删除原始记录或映射会使相关报告消失，分叉副本不成为替代账本。该视图用于排查与观察，不是不可变账单或上游费用证明。

接口、分页和权限见[Server 参考](server-reference.md)。需要核对 Server 账本的未知计数时使用[管理员用量核对](model-usage-reconciliation.md)，该流程不修改设备报告。

## 跨电脑调用

展开“跨电脑模型调用”读取当前空间的独立请求记录，支持搜索和分页；这里使用上方同一 UTC 月份，范围是整个当前空间，不按整机报告的电脑选择器筛选。记录保存每次尝试、状态、执行及来源电脑名称、实际提交者、模型所有者与资源原所有者。提交者和模型所有者可以读取各自有关的记录，管理员身份本身不扩大可见范围。

跨电脑汇总按请求接受时间归入 UTC 月份，涵盖符合相同搜索条件的所有分页。逻辑请求与实际尝试分别统计，内部重试不会增加逻辑请求数；每项 Token 保留报告覆盖次数，缺失不记为零。展开后才加载汇总，修改月份／搜索或手动刷新时更新。没有自有电脑的协作者也能选择月份查看自己的记录。

“导出跨电脑整月 CSV”保存当前快照，包含执行／来源电脑 ID 和名称、实际提交者、模型所有者、资源原所有者与 Provider／模型／协议。`row_kind=total` 为总计，`model_route` 为分项，不重复相加；迟到结果在下次刷新时计入原请求月份。此导出独立于设备直连报告。

这些报告来自来源电脑，不是 Server 直接观测的上游账单，也不扣平台预算。停止后仍可补记来源返回的最终用量；断线或 Server 退出导致没有完整回执时保留未知计数，不自动重新请求上游。请求内容、上游地址及 Key 不写入这份账本。跨电脑调用不在来源电脑创建 Agent 会话，因此不混入其会话直连报告。


## 月度汇总与导出

整月汇总按 Provider、模型和协议区分来源，展示尝试、完成、失败和未完成数量，以及输入、输出、缓存读取／写入和推理 Token。每项 Token 同时保留已上报次数：全部缺失时为空／未提供，有部分计数时只合计已知部分，不把其余尝试推算为零。结束结果延迟同步后，刷新即可获得新的快照；刷新汇总不需要先加载全部明细。

“导出汇总 CSV”导出当前月份和搜索条件下的同一快照，包含电脑 ID／名称、UTC 时间、来源和各模型分组。`row_kind=total` 是总计，`row_kind=model` 是分项，两者不要再次相加。未上报的 Token 单元格为空，明确上报的零为 `0`；`*_reported_attempts` 表示计数覆盖范围。UTF-8 文件可用于表格软件，名称和模型等文本会转义引号、换行及公式前缀。

接口 `GET /api/v1/model-computers/{executor_id}/usage/summary` 接受 `month` 和可选 `query`，返回 `source`、`period`、`observed_at_ms`、`totals`、`groups`。不接受分页游标或条数，最多返回 10000 个 Provider／模型／协议分组；超出时明确报错，需缩小搜索范围，不静默截断总量。每次读取复核电脑所有权和空间权限，跨空间／账号切换取消旧请求。删除原始记录／会话映射的语义与明细相同；此导出不包含下方独立的跨电脑调用账本。
