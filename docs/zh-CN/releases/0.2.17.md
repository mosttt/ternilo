# Ternilo v0.2.17

本版修复运行状态、会话操作和文件展示问题。

- 修复 SQLite 整体回滚后异常连接被重复使用，导致事务、就绪检查和请求恢复持续失败的问题。
- 运行中修改会话权限会立即提示等待当前轮次完成或先停止，不再阻塞历史加载；空闲后仍可修改，完整访问仍需确认。
- 修复 Server 接入电脑的子会话打开入口。主会话增加子 Agent 启动、协作状态和直接打开入口。
- 电脑离线或网页连接中断时显示运行状态待确认，不再把缓存的思考与工具状态持续计时。重连后恢复真实状态。
- 聊天中的工作区图片支持预览与放大，沿用会话文件权限；支持 Node 路径占位符，不要求把图片复制到工作区根目录。
- 全部完成的待办退出输入框上方，历史记录保留；工具说明补充进度更新与交付前核对要求。
- 文件页归并同一路径的生成记录，默认显示最新已加载版本；展开历史版本可分别预览、下载。
- 目录选择器显示实际路径，并提供上级目录入口。
- 命令授权按操作、用途、影响展示，完整命令可展开检查；等待授权与历史记录保持一致，旧请求明确提示缺少说明。

相关界面支持中文、英文、韩文和手机窄屏。

## 升级

请同时更新 Server 和接入电脑的 `ternilo`。Server 拉取 `ghcr.io/mosttt/ternilo-server:0.2.17` 后重新创建容器；仅重启旧容器不会更换镜像。本机先停止 Ternilo，再替换程序或使用原安装方式更新，保留原数据目录和配置，然后重新启动。

本补丁不需要资源迁移启用命令。资源迁移与恢复继续留在独立开发分支，Work 不包含在本版。Desktop 安装器仍未签名／公证，生产自动更新尚未启用。
