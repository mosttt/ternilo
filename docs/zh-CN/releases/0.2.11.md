# Ternilo v0.2.11

工作区现在可以移动到同一空间的其他管理项目。当前管理者在工作区操作菜单选择“移动到项目…”，选择目标并确认；桌面和手机使用同一流程，支持中文、英文和韩文。

- 保留工作区／会话标识、历史、文件、电脑绑定、管理者以及原执行项目和用量归属。文件与执行身份迁移、个人资源转团队仍属后续独立阶段。
- 默认取消原项目继承的访问并关闭目标项目共享；只有明确勾选后才采用目标项目规则。直接工作区／会话授权保留。
- 校验当前管理者、同空间目标、目标项目内同名冲突和单调迁移版本；旧确认不能覆盖迁移往返后的新状态。
- 各 Server 在事务提交后刷新权限、资源列表和会话订阅。共享数据库的实例应先统一版本，再使用项目迁移。

六目标程序、桌面安装器及 AMD64／ARM64 Server 镜像随发行提供。Desktop 签名、公证和生产自动更新仍等待发行者资料。
