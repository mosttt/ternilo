# Ternilo v0.2.8

本次修复移动端设置交互，并完善会话历史加载提示。

- 打开会话时显示历史加载动画；第一页内容先显示，后续分页仍保留加载提示，完成或失败后结束。切回缓存会话继续立即显示。
- 插件开关恢复正常形状，点击区域与可见轨道分开，桌面和手机均可通过点击或键盘切换。
- Agent 预设显示包含继承插件的完整只读 Profile，以及可编辑的预设覆盖 JSON。修改覆盖实时更新预览，未修改的基础插件继续继承。
- 修复预设编辑器窄屏横向溢出和文字裁切。
- 电脑详情的内容区域支持手机触摸滚动，取消和保存按钮保持可见；窗口高度缩小时，正在编辑的输入框滚动到可见区域。
- 中英文说明同步更新 MCP 插件配置入口；中英文 README 加入 LINUX DO 友链。
- 更新 DOMPurify 至 3.4.16、source-map-js 至 1.2.2，修复上游已公布的安全问题；前端依赖审计通过。参见 [DOMPurify 公告](https://github.com/advisories/GHSA-p98j-92pf-mc4p)和 [source-map-js 公告](https://github.com/advisories/GHSA-68fv-2mgg-jv7q)。

提供六个平台程序与桌面安装器，以及 AMD64／ARM64 Server 镜像 `ghcr.io/mosttt/ternilo-server:0.2.8`。稳定版公开后更新 `latest`。Desktop 签名、公证和自动更新仍未启用。
