# Ternilo v0.2.18

本版改进模型选择、问答与授权交互，并修复历史加载和模型调用错误提示。

- Ask 选项较多时可在卡片内滚动，翻页、跳过和提交按钮保持可见；切题、折叠与展开保留已选答案和补充输入。
- 个人空间的新会话默认模型同时用于从 Server 新建的接入电脑和托管会话，也可恢复为“每次新会话时选择”。已有会话、团队空间和电脑本地默认设置不变。
- 已有可用模型但当前会话尚未选择时，直接提示“选择模型”，不再要求重复配置 Provider；新建时也不会复用模型不同的旧空白会话。
- 命令授权改用简短自然段说明操作和重要影响，历史与底部卡片保持一致，完整命令仍可展开。旧格式的授权请求继续兼容。
- 切换会话时保留已加载的部分历史，回来后先显示已有内容，再续读较早记录；初始化断线后保留正文并自动恢复。
- 区分 DeepSeek 余额不足、OpenAI 余额／支出额度和请求限流，给出具体处理方向；共享模型提示仍不公开上游原始正文或密钥。

相关界面支持中文、英文、韩文及手机窄屏。

## 升级

Server 拉取 `ghcr.io/mosttt/ternilo-server:0.2.18` 后重新创建容器；只重启旧容器不会换成新镜像。接入电脑上的 `ternilo` 建议同步更新：先停止程序，再替换二进制或使用原安装方式更新，保留原数据目录和配置后重启。

本版不需要资源迁移启用命令。尚未完成的资源迁移功能及 Work 不包含在本版。Desktop 安装器仍未签名／公证，自动更新保持关闭。
