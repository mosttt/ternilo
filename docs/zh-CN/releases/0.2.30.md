# Ternilo v0.2.30

## 模型决定网页工具

网页搜索和读取可在每个模型中继承 Provider 默认值，也可独立覆盖。账号模型和设备本地模型使用同一配置规则；外部集成仍在执行电脑运行，凭据沿用现有授权边界。选项统一为“关闭”“模型内置”“外部集成 · 服务名”，中英韩同步。

不再用模型名称白名单阻止启用内置搜索、创建会话或选择默认模型。供应商是否支持在实际发送时判定：明确拒绝时保留输入和会话，显示可理解的原因，用户可切换模型后继续；不静默降级或自动重复收费请求。

## 更新不再依赖任务协议

新增独立版本的维护通道。后续任务协议不匹配时，电脑仍可显示“维护在线”，接收远程更新并恢复任务连接。更新仍由已有客户端及独立安装辅助进程完成，不新增常驻服务。更新命令、状态、暂停与撤权沿用原电脑身份；Server 重启后维护身份和命令信箱保留。

## 升级

**首次需手动升级 Server 和所有接入电脑到 v0.2.30。** 更早客户端没有独立维护通道；仅更新 Server 无法为它们补上该功能。等待正在运行的任务结束后，按原方式更新完整客户端包、拉取 `ghcr.io/mosttt/ternilo-server:0.2.30` 并重建 Server。保留实例数据、凭据、服务参数和已启用的更新配置，不要删除电脑登记。

手动升级若改变了程序目录，请用新版程序按原重启方式重新启用远程更新并重启一次，以刷新安装位置登记。

本版 Executor 协议 51、维护协议 1、数据代次 1。签名清单的维护基线为客户端 0.2.30，Server 范围为 `>=0.2.30, <0.3.0`；后续任务协议变化不再单独提高该基线。跨数据代次、维护协议自身不兼容或客户端停止运行时，仍需人工处理。

详见[网页访问](https://github.com/mosttt/ternilo/blob/v0.2.30/docs/zh-CN/web-access.md)、[客户端更新](https://github.com/mosttt/ternilo/blob/v0.2.30/docs/zh-CN/client-updates.md)。
