# Ternilo v0.2.32

## 归档与删除

归档主会话会同时归档真正的子 Agent 后代、停止相关任务并暂停队列；普通分叉会话保持独立。恢复会重新显示这条委派分支，不自动重跑任务或恢复队列。

归档列表支持所有者永久删除单条记录，提供中英韩确认和失败重试。删除保留其他会话及工作目录文件；云端父记录删除后，直接子会话解除该父子关联，执行目录隔离关系不变。

## 内存与执行路径

启动时流式读取历史并写入搜索索引，队列恢复只保留输入消费凭据和调度事实，避免把所有历史正文集中放入内存。

运行时增加已提交会话事实与轮次索引。轮次检查、作者溯源、目录准入、结果提取及队列收尾按需读取，不再为这些操作复制整份会话历史。事件同步落盘、输入持久化、权限检查和调度来源校验保持不变。

## 核心插件接口变化

内部 Sessions 服务从 `ternilo/sessions@1` 升为 `ternilo/sessions@2`，新增轻量摘要、轮次事实、轮次事件和单事件读取。直接实现或声明依赖旧接口的自定义核心插件需要适配并重新编译；内置插件同步升级。配置、会话日志、数据库和 Node 传输格式不变。

## 升级

更新 Server 镜像为 `ghcr.io/mosttt/ternilo-server:0.2.32`，并更新电脑端完整客户端包。已启用维护通道的 v0.2.30 及更新客户端可从 Server 发起升级；更早版本仍需手动安装。保留数据、电脑登记和原服务配置，无需迁移数据库。

详见[客户端更新](https://github.com/mosttt/ternilo/blob/v0.2.32/docs/zh-CN/client-updates.md)和[核心架构](https://github.com/mosttt/ternilo/blob/v0.2.32/docs/zh-CN/architecture.md)。Desktop 安装器仍未签名，自动更新保持关闭。
