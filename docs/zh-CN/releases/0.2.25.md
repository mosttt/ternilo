# Ternilo v0.2.25

本补丁修复客户端远程更新的等待与状态提示，界面支持中文、英文和韩文。

- 将本机启动健康检查从约 30 秒改为按实际时间计的 120 秒，避免启动较慢的电脑被提前回退；仍验证运行版本并保留超时恢复。
- 遇到重启前遗留、无法确认完成的执行资源时，明确报告对应记录，不再持续显示“等待任务结束”，也不会自动删除记录或中断任务。
- 在客户端下载前核对服务管理器与当前进程是否匹配，安装前再次确认。Supervisor 支持其完整进程名，例如 `ternilo:ternilo_00`。
- 新版已经正常运行、但上次自动更新未能确认结果时，明确提示“无需再次更新”，保留诊断，不再引导重复升级。同步改善启动、重连和回退提示。

## 升级

Server 按原方式拉取 `ghcr.io/mosttt/ternilo-server:0.2.25` 并重新创建容器。Executor 协议仍为 49，数据代次仍为 1，现有 v0.2.23／v0.2.24 客户端可继续连接。

**已遇到慢启动回退或旧执行记录阻塞的电脑，本次建议手动安装 v0.2.25，并保留数据目录与配置。** 自动更新由当前安装的客户端执行；只更新 Server 不会替换旧客户端中的 30 秒等待逻辑。安装本补丁后，后续远程更新才会使用新的启动等待与诊断。

Supervisor 的 `--service` 必须与 `supervisorctl status` 显示的完整名称一致。未知执行记录须由电脑管理者核对实际进程后处理；不要为了升级直接删除所有运行记录或锁文件。操作步骤见[客户端更新指南](https://github.com/mosttt/ternilo/blob/v0.2.25/docs/zh-CN/client-updates.md)。

Desktop 使用对应平台的新桌面包；安装器仍未进行系统代码签名／公证，桌面自动更新保持关闭。
