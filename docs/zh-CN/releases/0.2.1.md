# Ternilo v0.2.1

本次改进 Server 首次部署，二进制与 Docker 都可以直接启动 `serve`，通过启动日志中的初始化 Key 在网页选择数据库并创建管理员。完成设置后保存私有配置，后续重启保留原账号与数据库。

- 初始化、登录和使用页面按浏览器首选语言默认显示中文或英文，手动选择保存后优先覆盖。
- 网页可选择默认 SQLite，或填写 PostgreSQL 运行账号及可选建表账号；初始化 Key 在数据库访问前校验，完成后失效。设置未完成的重启输出新的 Key。
- 终端设置命令统一为 `ternilo-server setup`，提供隐藏输入向导及一次性自动化参数。日常 `serve` 不接受管理员账号参数，不会因重启重建或重置账号。
- 中文与英文部署文档分别说明原生二进制、外部 PostgreSQL、Compose 自带 PostgreSQL、HTTPS 网关和临时 SSH 访问。Release 附带 `compose.server.postgres.yml` 与 `postgres-init.sql`。
- 命令行、环境变量、保存配置与默认值按此顺序应用；网页已保存的数据库信息不需要重复写入环境变量。`--public-url` 可在网页配置。
- 优化较早会话历史页的读取，通过字节位置查找边界，避免每次加载都扫描整份会话记录。

客户端与 Server 提供 Linux x86_64／ARM64、Windows x86_64／ARM64、macOS Intel／Apple Silicon 产物。Windows 为 ZIP，其余命令行归档为 tar.gz；Desktop 提供对应安装包。`ghcr.io/mosttt/ternilo-server:0.2.1` 提供 AMD64／ARM64 镜像。Desktop 安装包仍未启用发布者签名、公证和自动更新。
