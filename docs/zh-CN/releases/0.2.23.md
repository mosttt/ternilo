# Ternilo v0.2.23

本版新增 Server 发起的客户端远程升级，并将侧栏电脑分组改为支持单台或全部电脑的下拉选择。相关界面支持中文、英文和韩文。

- 在“用户设置 → 我的机器”更新单台或批量接入电脑。Server 下载并缓存官方发行包，电脑独立验签后安装；生产签名私钥只用于发行，不部署到 Server 或客户端。
- 电脑所有者在本机明确启用。更新等待对话、子任务、排队任务和后台作业结束，不中断正在执行的工作；空闲 MCP／LSP 常驻服务不会阻止更新。
- 支持直接启动、持久 systemd 服务及 Supervisor 的重启方式。新程序启动失败时回退，安装中断时可在本机恢复；保留配置、会话、电脑身份和凭据。Windows 当前支持直接启动方式。
- 侧栏“按电脑”视图提供电脑下拉框，可显示单台或全部电脑，记住当前账号和空间的选择与页面内滚动位置。搜索仍覆盖可见范围，切换筛选不切换当前会话。
- Ternilo 与 Ternilo Server 的“关于与诊断”显示各自运行的程序版本，不依赖所选工作区或插件目录版本。
- 短屏侧栏为会话列表保留可操作空间，底部导航单独滚动，保持触摸按钮大小与所有入口可达。
- 修复 PostgreSQL 请求取消时连接遗留只读事务、导致后续请求失败的问题。
- 修复连续工具授权时旧刷新结果覆盖新问题、导致确认卡片消失的问题。
- 更新密码学、证书验证与前端依赖，包含 ctutils 0.4.4、DOMPurify 3.4.17、Vitest 4.1.12，修复已知安全问题。

## 首次升级需要 Server 与接入端一起更新

本版使用 Executor 协议 49，不接受旧协议连接。请先备份 Server 数据库、配置和客户端数据，在同一维护窗口停止旧服务，将 Server 与接入端都升级到 0.2.23 后重新启动。

Server 拉取 `ghcr.io/mosttt/ternilo-server:0.2.23` 并重新创建容器；客户端使用原安装方式更新，或替换完整客户端包。保留原数据目录与配置，Windows 保留主程序旁的沙箱辅助程序。首次升级不能通过旧版客户端的远程更新完成。

升级后，电脑所有者在本机运行 `ternilo updates enable --help`，按实际启动方式启用远程更新，并重启客户端一次。以后同一协议和数据代次内的兼容版本可从 Server 更新。启用、状态及恢复命令见[客户端更新指南](https://github.com/mosttt/ternilo/blob/v0.2.23/docs/zh-CN/client-updates.md)。

远程更新适用于官方 browser／CLI 客户端包，不替换容器或桌面安装器。Desktop 安装器仍未进行系统代码签名／公证，桌面自动更新保持关闭。资源迁移与 Work 不包含在本版。
