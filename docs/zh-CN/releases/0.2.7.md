# Ternilo v0.2.7

本次完善 OAuth2／OIDC 首次注册，并修复手机界面及 Turnstile 组件重建后的回调冲突。

- 登录方式返回可用的 `preferred_username`／`username` 和邮箱时自动注册；用户名重名或不符合格式时选择用户名，缺少邮箱时才补填邮箱。
- 上游邮箱直接使用，不再提供编辑框；后端忽略试图替换该邮箱的注册请求参数。不按邮箱合并账号；重名邮箱提示登录原账号并显式关联身份。
- 自动注册继续执行邀请、审核与人机验证策略。需 Turnstile 时先完成验证，缺少邀请不能注册，审核申请不会直接获得访问权限。
- 手机电脑管理卡片一行一个按钮，完整展示详情、暂停／恢复、吊销和移除操作。
- Turnstile 尺寸／主题切换后隔离旧组件回调，防止旧成功、失败或过期状态覆盖新组件。重试与过期刷新由界面统一处理，并直接显示 Cloudflare 错误码。
- 双语恢复文档补全登录设置重置范围和 Docker 操作命令，避免误重新生成实例主密钥。

Server 继续验证 OIDC 签名、PKCE、nonce、UserInfo 身份及 Turnstile Siteverify；本版没有更改已保存登录设置的格式。手机验证组件的接入修正不代表 Cloudflare 一定接受某次生产挑战，持续失败应按页面错误码核查浏览器、网络和提供方配置。

提供六个平台程序与桌面安装器，以及 AMD64／ARM64 Server 镜像 `ghcr.io/mosttt/ternilo-server:0.2.7`；`latest` 随稳定版公开后更新。Desktop 签名、公证和自动更新仍未启用。
