# Ternilo v0.2.24

本补丁改善 Server 工作台加载和电脑管理，相关界面支持中文、英文和韩文。

- 先显示 Server 已保存的工作区列表和导航，再独立加载所选电脑的会话及配置。电脑响应慢时仍可切换电脑或进入设置；加载提示和失败重试留在当前会话区域。
- 打开工作区默认沿用侧栏选中的电脑。手动更换后刷新列表不会改回默认值；选中电脑离线时明确提示，不会自动改在另一台电脑上创建工作区。
- “我的机器”和更新窗口统一显示“当前版本 → Server 配套版本”：向上箭头表示可更新，勾号表示在线且版本匹配；无法确认或更新时显示叉号及原因。正常状态不再重复显示第二行说明，弹窗刷新结果同步到电脑列表。
- 修复后台刷新期间恢复插件继承后输入框显示空白的问题，保留用户未保存的编辑。
- 修复退出账号时旧模型面板被缓存刷新再次唤起、发出已失效请求的问题；迟到结果不会重新填入新账号或空间。
- 更新 Tokio 至 1.53.3，包含官方针对 AsyncFd I/O 安全问题（RUSTSEC-2026-0386）的修补；同时更新测试依赖 undici 至 8.12.3。

## 升级

从 v0.2.23 升级时，Executor 协议仍为 49，数据代次仍为 1。先将 Server 镜像更新为 `ghcr.io/mosttt/ternilo-server:0.2.24` 并重新创建容器；现有 v0.2.23 客户端可继续连接。已启用远程升级的 browser／CLI 客户端可随后从“我的机器”更新，其他客户端按原安装方式更新，保留数据目录与配置。

更早版本仍需按 [v0.2.23 升级说明](https://github.com/mosttt/ternilo/blob/v0.2.24/docs/zh-CN/releases/0.2.23.md)先安排 Server 与接入端成套升级。Desktop 使用对应平台的新版桌面包；安装器仍未进行系统代码签名／公证，桌面自动更新保持关闭。
