# Ternilo v0.2.26

本补丁为 macOS 用户级 LaunchAgent 增加远程客户端更新支持，并修复紧凑显示下问答内容被折叠的问题。界面提示同步支持中文、英文和韩文。

- 使用 `--restart launch-agent` 配置实际的 plist Label、文件位置和登录域；默认读取当前用户的 LaunchAgents 目录和 GUI 域。
- 下载前与安装前核对 plist 和当前服务 PID。安装时卸载 Agent，避免 KeepAlive 在文件替换期间重启旧程序；安装或回退后按原 plist 重新加载、启动服务。
- 保留现有签名验证、空闲检查、数据与配置、120 秒健康确认及本机恢复流程。direct、systemd 和 Supervisor 的使用方式不变。
- 在提问卡片中回答后，提问前的 AI 回复、问题和你的回答保持可见；刷新、历史补齐或切回会话时不会被归入折叠过程。同一轮内追加输入前的回复也保留显示。

## 升级

首次为 LaunchAgent 启用本功能，请先手动安装包含此适配的 v0.2.26 客户端，再使用运行 Agent 的同一账号执行：

```sh
ternilo updates enable --restart launch-agent --service com.ternilo.client
```

将 `com.ternilo.client` 换成实际 plist 的 `Label`。自定义实例目录须使用同一 `--data-dir`；其他 plist 位置和非 GUI 域见[客户端更新指南](https://github.com/mosttt/ternilo/blob/v0.2.26/docs/zh-CN/client-updates.md)。服务启动命令使用稳定的 `bin/ternilo` 入口，启用后按原方式重启一次再在 Server 刷新。GUI 域安装期间请保持登录。本适配不用于系统 LaunchDaemon 或 Desktop 安装器。

Server 可按原部署方式拉取 `ghcr.io/mosttt/ternilo-server:0.2.26` 并重新创建容器。Executor 协议仍为 49，数据代次仍为 1，不要求所有电脑同时停机升级。其他已启用远程更新的兼容客户端可继续使用原更新流程。
