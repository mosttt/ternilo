# Ternilo v0.2.31

## 子 Agent 与会话交互

修复 Server 新子会话可能读取创建前快照、导致网页访问授权失败的问题。同一授权问题避免重复提交；失败或已结束的子 Agent 不再被旧运行快照显示为“正在协作”，真正重新启动后仍正常显示。

Agent 预设卡片点击只查看，不再修改默认预设。已开始会话的“使用”按钮与会话工具栏保持一致：预设锁定，仍可查看、编辑及设置新会话默认值。

## 回答、错误和配置反馈

流式回答与最终内容使用同一 Markdown 布局，减少回答结束时的阅读位置跳动；保留问答前后消息与轨迹排版。子 Agent 授权说明展示任务、权限及额度影响，支持中英韩。已结束任务的短暂收尾不再立即阻止保存插件配置，运行中保护保持不变。

Responses 上游的图像复杂度参数拒绝显示明确原因，即使包装为 HTTP 502 也不重复发送相同无效请求。Ternilo 不添加图像 `complexity`，此类拒绝需要修正上游或中转的图像配置，不影响对话推理设置。

## 更新恢复与依赖修复

升级中的安装标记、配置或进度保存失败会进入安全恢复；原程序恢复并核验通过后，进度写入失败不再阻断重启。回滚与本地恢复也遵循相同规则。程序恢复或版本核验失败时仍保留保护标记，不启动不完整的安装。

更新 Wasmtime 至 48.0.8、pulldown-cmark 至 0.13.6，修复依赖安全公告涉及的问题。

## 升级

更新 Server 镜像为 `ghcr.io/mosttt/ternilo-server:0.2.31`，并更新电脑端完整客户端包。已启用维护通道的 v0.2.30 客户端可从 Server 发起升级；更早版本仍需手动安装。保留数据、电脑登记及原服务配置。维护基线仍为 v0.2.30，维护协议、执行协议和数据代次不变。

详见[客户端更新](https://github.com/mosttt/ternilo/blob/v0.2.31/docs/zh-CN/client-updates.md)与[发行流程](https://github.com/mosttt/ternilo/blob/v0.2.31/docs/zh-CN/ci-release.md)；Desktop 安装器仍未签名，自动更新保持关闭。
