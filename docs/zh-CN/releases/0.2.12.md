# Ternilo v0.2.12

本版修复空白会话无法移除，以及运行中的电脑会话保存插件配置时一直显示“正在保存…”的问题。

- 普通“新会话”优先复用同工作区、配置匹配且没有草稿、附件、引用或待处理任务的空白会话。连点合并为一次操作；工作区菜单的“另建会话”可提前准备多个任务，不设硬性数量上限。
- 空白会话提供重命名、归档和所有者确认删除入口。取消删除保留准备内容；删除不移除工作区文件。未发送的附件和引用在同一页面内切换会话时保留。
- 本机／Node 会话运行时，插件页说明等待原因，保留可编辑的字段，暂时禁用保存、启停和移除覆盖。具备停止权限的用户可在表单内停止当前任务；任务实际结束后，直接保存原编辑内容。后端及时返回 Conflict，保存不自动取消正在运行的任务。
- 直接打开 Server 插件设置页也能收到活动状态；补齐取消／失败后的活动通知，避免任务已经结束而提示仍停留在运行中。

请同步更新执行电脑上的 CLI／Desktop 与 Server，以获得对应的界面及后端修复。本版包含六目标程序、桌面安装器及 AMD64／ARM64 Server 镜像。Desktop 签名、公证和生产自动更新仍等待发行者资料。
