# Ternilo v0.2.19

本版修复工作区图片展示，并减少本地工具对外部安装和环境设置的依赖。

- 修复 Windows 盘符、本地文件 URL 和带空格的工作区图片路径无法展示的问题；图片仍通过已授权的工作区接口读取，工作区外的路径继续拒绝。
- 文件匹配和文本搜索改为内置实现，无需另外安装 `ripgrep`；保留忽略规则、结果上限和部分结果提示。
- Windows shell 按主机输出代码页处理旧编码，支持中文、韩文和 OEM 输出；保留原命令、退出码和系统安全策略。
- 非零退出和超时正确显示为工具失败；PowerShell 受限方法调用与语法错误有不同说明，原始输出仍可查看。
- 打开接入电脑上的会话时提前检查默认命令沙箱，缺少依赖或无法运行时说明应在哪台电脑修复，提供适用的安装命令和重新检查入口。
- Wasmtime 升级到 48.0.7，修复 RUSTSEC-2026-0378 和 RUSTSEC-2026-0379。

相关界面支持中文、英文和韩文。

## 升级

Server 拉取 `ghcr.io/mosttt/ternilo-server:0.2.19` 后重新创建容器。接入电脑上的 `ternilo` 也需要更新，才能获得内置搜索、Windows 解码和沙箱自检：先停止程序，替换二进制或用原安装方式更新，再保留原数据目录和配置启动。Windows 应更新完整安装包，并保留主程序旁的沙箱辅助程序。

本版不需要数据库迁移或资源迁移启用命令。资源迁移功能和 Work 不包含在本版。Desktop 安装器仍未签名／公证，自动更新保持关闭。
