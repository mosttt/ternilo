# Ternilo v0.2.5

本次修复通过 WSS 连接 Server 时的 Rustls 启动崩溃，并完善 OAuth2／OIDC 登录与注册管理。

- 实例设置支持多个具名 OIDC 登录提供方，分别配置、启停和保存密钥。登录页及原生账号关联页按名称选择，授权码、PKCE、刷新和 MFA 都绑定所选提供方。
- 注册条件新增“仅限 OAuth2 方式注册”，同时约束开放注册与邀请注册的密码入口。OAuth 邀请令牌跨跳转保留，并在创建账号时原子消费；已有账号仍可用密码登录。
- 账号状态移到名称旁，以文字、颜色和状态标签突出可使用、待审核、已封禁等状态，适配浅深主题和手机页面。
- 客户端、Server、Worker、Desktop 在启动入口显式选择 Rustls 加密后端，避免同时启用多个后端时 panic；证书与主机名校验继续执行。
- GHCR 的 `latest` 指向最新已发布稳定版的同一份 AMD64／ARM64 镜像索引，预发行版不覆盖它。生产部署默认固定版本号，双语文档同步说明两种选择。

认证管理及公开登录元数据使用 `oidc_providers` 列表；授权码交换、刷新及 MFA 请求包含 `provider_id`。不保留旧的单提供方接口。普通 OAuth2 服务商仍需提供本项目支持的 OIDC 身份合同，或单独适配。

客户端与 Server 继续提供 Linux x86_64／ARM64、Windows x86_64／ARM64、macOS Intel／Apple Silicon 产物，Server 镜像为 `ghcr.io/mosttt/ternilo-server:0.2.5`。Desktop 安装包仍未启用发布者签名、公证和自动更新。
