# Ternilo v0.2.10

本次修复本机会话日志在流式写入时被读取为不完整 JSON，导致网页出现历史加载失败的问题。

- 同一日志的独立存储实例共享读写保护，全量、增量、分页和单事件读取等待完整记录落盘；并发读者仍可共同读取。
- 分叉写入和日志删除使用相同保护。静态损坏日志继续报错，保留现有离线检查、备份和修复流程。
- 保留 v0.2.9 的初始化滚动、对话滚动、韩语界面和 Cloud 统计检查点；公开的 v0.2.9 标签保持不变。

提供六个平台程序与桌面安装器，以及 AMD64／ARM64 Server 镜像 `ghcr.io/mosttt/ternilo-server:0.2.10`，稳定版公开后更新 `latest`。Desktop 签名、公证和生产自动更新仍待资料；资源迁移另行推进。
