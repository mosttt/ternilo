# Ternilo v0.2.9

本次修复初始化页与对话阅读的滚动问题，新增韩语界面，并减少 Cloud 会话统计的重复历史读取。

- 初始化表单使用独立滚动区域，电脑滚轮、手机触摸滑动和键盘焦点可到达完整数据库设置、管理员字段和提交按钮，适配窄屏与短窗口。
- 修复 WebKitGTK 桌面回答结束后的滚动跳动；带代码块的流式 Markdown 与最终回答使用相同排版，保留向上阅读的位置。
- 新增韩语界面，支持浏览器语言检测、手动切换、保存偏好和本地化时间显示。
- 修复在设备本地模型设置中添加或修改 Provider 后，会话模型菜单仍使用旧缓存的问题；返回工作台即可选择更新后的模型。
- Cloud 会话统计保存可重建的数据库检查点；重复读取直接返回缓存，追加事件只增量计算。重新生成历史或检查点失效时从日志重建，读取仍校验当前查看权限。
- 同时读取统计和完整插件投影的 Live 请求保持共用历史视图；完整插件投影仍回放历史。
- 同步中英文协作、安全和架构说明，恢复旧电脑管理与四种 Agent 模式浏览器合同，并将初始化页面回归验证纳入发行检查。

提供六个平台程序与桌面安装器，以及 AMD64／ARM64 Server 镜像 `ghcr.io/mosttt/ternilo-server:0.2.9`。稳定版公开后更新 `latest`。Desktop 签名、公证和自动更新仍未启用；资源跨项目、跨团队与跨主机迁移另行推进。
