# Ternilo v0.2.13

本版增加角色模型、独行／协行／并进协作模式、上下文优化与项目交付工具，并修复历史加载时对话阅读位置跳动。

- 调查、实现、复核可分别选择模型和推理强度。协行默认 4 个、并进默认 8 个并发子代理，均可设置 1–32；Workflow 按相同上限分批执行。只读角色、模型授权、额度和取消继续由宿主落实。
- 工具定义可按需加载；自动上下文压缩提供结构化交接摘要。工具输出有总预算，文件读取可选缓存并检测变化，AST 代码图谱支持 Rust、TypeScript、JavaScript、Python 和 Go。
- Team 用量页按实际模型统计主／子代理 Token，并按浏览器内填写的单价估算金额。缓存与推理用量不会重复计算，缺失用量和价格标明未知。
- 提示前缀支持可选 Anthropic 缓存标记；自动推理强度先提供观察模式，不改变实际模型参数。
- 项目记忆与历史检索分开；Git 提交限定文件路径；GitHub 提供 PR 读取、草稿创建和指定 head SHA 的合并。当前隔离 Worker 没有外网，GitHub 操作使用本机或接入电脑。
- Markdown／静态 HTML 可通过执行端浏览器实际渲染并保存截图。修改源文件后须重新渲染，查看截图后才能记录该版本检查结论；自动发现的布局和资源问题会阻止通过。需自行准备隔离环境内可用的 Chrome／Chromium。
- Skill 前置信息改用维护中的 YAML 解析器，保留多行文本、字段别名与现有布尔形式。
- 历史分批补齐和用量栏晚到时，触底位置及正在阅读的段落保持稳定；多轮历史窗口保留最新内容。空闲配置保存不会再把短暂的元数据读取误报为任务运行。

界面和提示适配中文、英文、韩文及手机窄屏。请配套更新 CLI／Desktop、Server 和现有 Worker。新增功能保持插件配置入口，`ternilo-work` 仍只预留框架，资源迁移中的独立工作不包含在本版。Desktop 签名、公证和生产自动更新仍等待发行者资料。
