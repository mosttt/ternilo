# Ternilo v0.2.14

本版集中展示插件参数，并让团队面板直接配置当前会话的协作模式。

- “设置 → 插件”默认进入“集中配置”，可按插件或参数搜索、快速定位；每个插件独立保存、放弃修改或移除会话覆盖。
- Agent Team 新增“协作设置”，直接选择独行／协行／并进、角色模型、权限和子代理限制。三个配置入口共享草稿，保存、启停和恢复继承同步显示；保存途中切换入口也不会重复覆盖配置。
- 明确区分同时运行的子任务数与保留的子代理实例数，实时显示两者约束下的并发上限；补齐中文、英文、韩文名称和说明。
- 团队刷新与关闭按钮对齐，打开面板时聚焦标题；手机可触摸滚动到完整表单和保存按钮。
- 修复首轮对话及输入区高度变化时自动跟随遗漏的问题，继续保留主动上滑后的阅读位置。

未保存草稿在同一页面内切换入口或关闭面板后保留，刷新网页会丢弃。当前会话的设置不会批量改写已创建的子会话。本机及 Server 接入电脑的会话运行时可以继续编辑，任务结束或主动停止后再保存。

请配套更新 CLI／Desktop 与 Server；接入电脑需要使用支持协作配置的 Ternilo 版本。资源迁移与恢复仍在独立开发，未包含在本版。Desktop 签名、公证和生产自动更新继续等待发行者资料。
