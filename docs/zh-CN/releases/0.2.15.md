# Ternilo v0.2.15

本版完成本轮协作与上下文能力的补齐，继续沿用独行／协行／并进、角色模型及同步插件配置入口。

- 输入框的上下文弹层显示最近请求的文本组成：系统指令、工具定义、对话、工具输出和推理／续传状态。统计来自压缩与预算处理后的请求，按字符计数，与上游报告的 Token 用量分别展示。
- 会话日志支持按工具设置单条输出上限，再应用历史总预算；完整输出仍可从附件读取。代码图谱可查询所选文件内的直接和间接候选调用者，并标明重名、动态目标及截断等限制。
- “自动调整推理强度”可让主模型逐步选择已配置的低／中／高档位，默认关闭。手动档位仍是上限；Server 和来源电脑核对实际支持范围，模型与保存设置不会被改写。
- GitHub 工具增加只读发布列表、最新正式版、指定标签／ID 和附件分页查询。隔离 Worker 的网络边界保持不变。
- 文档渲染支持 Markdown 公式，内嵌字体可在离线或字体较少的执行环境中完整显示运算符。无效公式、外部资源和公式溢出继续阻止文档检查通过。
- Rustls 升级至 0.23.46，Wasmtime 升级至 48.0.6，修复本次发行安全审计发现的 TLS 与 WebAssembly 运行时漏洞。

新增设置与展示支持中文、英文、韩文及手机窄屏，并已验证本机、Server 接入电脑和现有 Worker 的对应流程。请配套更新 CLI／Desktop、Server 和自行部署的 Worker。

资源迁移与恢复仍留在独立开发分支，不包含在本版。Desktop 安装器仍未签名／公证，生产自动更新尚未启用。
