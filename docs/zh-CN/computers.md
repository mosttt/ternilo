# 管理已登记电脑

Server 的“用户设置 → 我的机器”管理当前空间中属于自己的电脑；具有空间管理职责的人也可以在“空间管理 → 电脑”使用对应管理入口。电脑接入步骤见[远程访问](remote-access.md)。

每台已登记电脑提供“详情与编辑”“暂停接入／恢复接入”“吊销电脑”和“移除登记”。吊销后的电脑可“恢复原电脑接入”。详情仅在打开时读取；已移除登记仅在点击“查看已移除登记”后加载。

## 名称、备注和详情

登记时只填写电脑名称，系统生成固定、不可修改的电脑 ID。ID 用于内部关联和路由，在详情中查看；列表、工作台分组、标题路径栏、目录选择器、模型与用量页面使用名称。

名称不能为空，在同一账号、同一空间的登记列表中唯一，区分大小写并去除首尾空白。尚未使用的有效登记凭据也会预留名称。改名不改变 ID、凭据、目录或资源绑定。移除登记后名称可供新电脑使用；恢复原登记遇到同名电脑时需另选名称。备注保存在 Server。

详情显示登记 ID、归属账号、项目、连接与登记状态、登记时间、最后联系、凭据签发及最近使用时间、已登记工作区和关联会话数量。已连接过的电脑还可展开连接诊断，查看协议、运行实例和能力目录。最后联系取 Server 保存的最近心跳或认证时间；未记录的信息如实标示，不推断主机名或 IP 地址。

手机上，内容超过弹窗高度时可在详情区域上下滑动，查看并编辑名称、备注和连接诊断。取消和保存按钮保留在弹窗底部；可用窗口高度缩小时，正在编辑的输入框会滚动到可见区域。

修改按当前管理版本提交。其他页面先改动了同一台电脑时，会提示刷新后重试，防止覆盖新信息。

## 暂停与恢复接入

暂停拒绝新的 Server 连接及远程请求，保留原凭据。恢复后，运行中的 Node 可用原凭据重连，无需重新登记；电脑和网络仍需可用。

暂停接入不会关闭本机 Ternilo 服务或强制终止所有本机任务。通过 Server 使用模型的任务可能因连接不可用而中断，需要检查结果。要正常停止本机服务，使用 `ternilo stop --data-dir <实例目录>`。

## 吊销与移除登记

| 操作 | 凭据 | 登记列表 | 数据 |
|---|---|---|---|
| 暂停接入 | 保留，暂停期间不能接入 | 保留，可恢复 | 保留 |
| 吊销电脑 | 原凭据失效，可恢复原身份 | 保留并标为已吊销 | 保留 |
| 移除登记 | 原凭据失效，可从已移除登记恢复原身份 | 默认隐藏 | 工作区、会话历史及项目文件保留 |

吊销和移除需要明确确认。移除登记不删除底层资源关联记录，仍可查看已同步到 Server 的离线历史；侧栏中的相关工作区因此可能继续保留。未同步的内容仍在原电脑的数据目录中。

## 恢复原电脑接入

在已吊销电脑上选择“恢复原电脑接入”；已移除电脑先点击“查看已移除登记”。确认名称并生成恢复命令。此操作保留原 ID、归属账号、绑定项目及资源引用，签发新凭据；原凭据继续失效。它不会自动重做历史任务。

在原电脑上正常停止旧实例，再运行恢复命令。使用自定义实例目录时，在命令后添加 `--data-dir "<原实例目录>"`。数据目录绑定会沿用，新建空目录不能代替原实例；目录丢失时须先恢复该实例的备份。成功验证连接后，新的连接配置私有保存，后续重启直接使用同一目录即可。

“登记新电脑”生成独立 ID，适用于新的独立实例；不能用相同名称自动认领已有电脑。同机多实例各用独立目录、端口、ID 和凭据。程序重启、断网、电脑 IP 变化或改名不重新登记。凭据轮换单独后移，当前恢复入口只处理已吊销或已移除的电脑。
