# 标识与凭据命名

对外凭据与浏览器会话 ID 使用 `ter_` 加用途短码。`ter` 代表 Ternilo；短码区分用途，后面仍保留完整的随机值或摘要。

| 前缀 | 用途 |
|---|---|
| `ter_s_` | 浏览器登录会话的公开 ID，用于查看与撤销，不是登录凭据 |
| `ter_pc_` | 系统生成的电脑实例固定 ID，不是接入凭据 |
| `ter_sa_` | 服务账号固定 ID |
| `ter_sk_` | 服务凭据的公开记录 ID，不是访问凭据 |
| `ter_t_` | 空间范围的服务账号 HTTP 访问凭据 |
| `ter_a_` | 原生账号登录访问凭据 |
| `ter_o_` | 本站签发的 OIDC 访问凭据 |
| `ter_r_` | OIDC 刷新凭据 |
| `ter_ev_` | 一次性邮箱验证凭据 |
| `ter_pr_` | 一次性邮件密码找回凭据 |
| `ter_b_` | Server 首次设置凭据 |
| `ter_n_` | Node 连接凭据 |
| `ter_e_` | Node 一次性登记凭据 |
| `ter_w_` | Worker 接入凭据 |
| `ter_i_` | 账号／团队邀请凭据 |
| `ter_m_` | 模型服务 API Key |
| `ter_d_` | 模型服务设备访问凭据 |
| `ter_c_` | 模型服务设备授权码 |

前缀用于识别用途，不代替身份、有效期、权限和撤销状态检查。公开会话 ID 无法用于登录；其余凭据只交给对应功能使用。界面中的短 ID 或 API Key 前缀只是辨认信息，不是完整凭据。
