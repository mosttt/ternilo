# 消息、附件与文件

侧栏“文件”统一管理已提交的附件和生成产物；会话内的文件入口打开同一页面，并自动按当前会话筛选。

返回文件页时会复用当前账号、空间和筛选条件下 30 秒内的目录快照，包括已加载的分页，避免每次切页重新读取。缓存仅在当前页面进程的内存中保存文件元信息，不持久化文件正文；收到任务或资源变更后失效，切换账号／空间时清空。点击“刷新”可立即重新读取，目录缓存不替代预览和下载接口的权限校验。

右上角“打开文件侧栏”读取当前会话绑定的真实工作目录，不是附件／产物历史库，也不是选择工作区。重复的顶部选择工作区按钮已移除，左侧入口和标题下路径仍保留。

会话标题下用一行显示接入电脑的登记名称、工作区名称、项目名称和实际路径；项目名称仅在权限允许时展示，不加“项目：”前缀。桌面和手机均可横向滚动查看完整内容，桌面也支持滚轮和键盘方向键。这一行仅展示信息，不再点击打开工作区选择器。Server 的实际路径通过既有的所有者专用接口读取，不从公开工作区别名推断，也不写入浏览器持久缓存。电脑离线或权限不足时显示对应说明，不把 `<local-workspace>` 当作真实目录。托管工作区不显示 Worker 主机路径。

手机隐藏这行的横向滚动条，刚进入页面也不显示；仍可左右滑动查看完整位置，不改变路径内容。

Server 聊天里出现的 `<local-workspace>` 会在显示时替换为已获准读取的实际路径；无法读取时改成可理解的工作区名称说明。替换仅作用于回答的文本节点，不修改原始会话事件、模型上下文或链接地址，也不解除共享会话的路径保护。切换账号、空间或工作区时不沿用上一目标的私有路径。

## 工作目录侧栏

目录按层展开，文件夹优先并按名称自然排序；点击文件打开预览标签，重复点击同一栏已打开的文件会选择原标签。可以新建目录标签、关闭标签、拖动标签到另一栏，也可以用“将当前标签移到另一栏”按钮移动；切换双栏、全屏或收起面板不会改变目录内容。移动端使用全屏面板，双栏上下排列。标签和展开状态按浏览器、账号与会话分别保存，不同步到协作者。

桌面文件栏默认占剩余工作区约一半宽度，可拖动分隔线调整；文件栏宽度与原事件详情面板分别记忆。窗口不足以并排显示时使用覆盖面板，不将两栏挤成不可读的窄条。

刷新按钮重新读取所在栏的目录和文件。预览支持 UTF-8 文本／代码、Markdown、HTML／SVG 安全渲染、PNG／JPEG／GIF／WebP 和 PDF；不运行 HTML 脚本，不加载外部资源或提交表单。文本可复制，完整且支持的文件可下载。Office 等格式暂不支持在线预览。每层最多显示 10,000 项，读取上限为 2 MiB；超限文本仅显示开头，超限二进制不预览，不提供截断下载。

文件读取限定在绑定工作区内，拒绝越界路径、符号链接和特殊文件。Windows 通过目录句柄逐层读取，同样拒绝目录联接、盘符路径和备用数据流，不以字符串前缀判断代替目录边界。Server 转发到实际 Node 或 Worker，不读取 Server 主机上的同名路径。托管工作区首次任务前尚无实体文件时会提示先初始化；无需模型即可读取已经存在的托管文件。

仅共享会话不会授予工作区读取权限，需要单独拥有工作区的查看权限。此面板只读，不锁目录，也不包含文件编辑、删除或上传；其他参与者、Agent 或外部编辑器仍可能更改实际文件。撤销工作区共享后，新的读取和文件命令结果查询会被拒绝；已经被合法下载的内容无法收回。事件详情面板及附件／产物文件库继续独立保留。

## 在应用中打开

有桌面会话的 Linux 电脑会根据进程 `PATH` 中真实可执行程序显示可用应用，例如 VS Code、Cursor 和文件管理器。主按钮在上次选择的可用应用中打开当前绑定目录，旁边下拉菜单选择并打开其他应用；选择仅保存在当前浏览器账号下。此入口在无桌面、没有可用应用或托管 Worker 场景不显示；其他操作系统和 `.desktop`／Toolbox 等额外发现方式尚未接入。

Linux 应用图标从对应 XDG desktop entry 的 `Icon=` 读取，查找 hicolor／pixmaps 中的 PNG 或 SVG；缺失时显示小圆角方框。菜单用底色标记当前应用，名称如 `VS Code` 保持简短；页面刷新后重新发现安装情况。

此功能只在本机 Ternilo 界面提供。Server 不显示“在应用中打开”，并拒绝启动请求，包括资源所有者的请求，避免在被控电脑上意外弹出程序。Server 中的网页文件树、预览和下载仍可使用，权限规则不变。

本机启动使用固定应用目录与独立路径参数，不拼接 shell 命令；子进程只继承启动桌面所需的环境变量，不传递 Provider Key 或 Server 凭据。按钮成功表示已请求启动，不保证桌面窗口已经打开。

若要用浏览器所在电脑的 VS Code 编辑远程工作区，需要另行配置 Remote SSH 或 Remote Tunnels；用本地文件管理器访问则需对应的远程文件协议。当前 Ternilo 连接不是这些协议的接入通道，也不会把被控端的路径作为本机路径打开。下载得到的是文件副本，不会自动把本地修改写回远端。

## 消息、附件和交付物

网页输入框支持 UTF-8 文本文件和图片。文本文件最大 512 KiB；图片原文件最大 20 MiB，还受分辨率限制，上传前会自动缩放、压缩到 4 MiB 以内。下载图片得到的是实际上传并保存的规范化版本。还可以选择文件、目录等上下文引用，发送前可检查或移除待发送引用。输入 `/` 可查看当前可用的命令；命令是否可用取决于会话已启用的能力。

输入 `@` 可选择当前工作区的文件、目录或可用会话作为引用。候选列表中用上下方向键移动，Enter 选择；选中目录后按 Tab 或向右键进入，Esc 关闭列表。发送前可以移除引用，引用不会扩大当前会话的文件或共享权限。

`/read`、`/write` 等直接工具命令由对应工具执行，不额外调用模型解释命令，仍遵守权限、审批和停止操作。已知命令的参数错误会显示用法提示；未知的 `/...` 文本仍可能作为普通任务发送给模型。`/plan`、`/skill` 和 `/feedback` 使用各自的专用流程。

回答支持 Markdown 表格、任务列表、代码高亮、数学公式和远程 HTTPS 图片。原始 HTML 按文本显示。流式回答尚未结束时，也可以阅读已经输出的部分。

桌面历史轮次的复制、编辑、重试、反馈、分叉以及时间／用量统计在鼠标悬浮该轮或键盘聚焦时显示；最新轮次的用户消息和回答始终显示这些区域，批量提交的用户消息按同一轮处理。手机和无悬浮能力的设备全部常显。操作区域保持原占位，显示与隐藏不引起聊天滚动跳动；产物文件不随操作区隐藏。

较长的工具或 Code Mode 结果默认只显示头尾预览：超过 12,000 字符的结果会把完整正文保存为附件，最大 64 MiB，可从页面打开。Agent 使用 `write_file` 或 `replace_in_file` 成功写入文件后，还会保存当时版本的交付物；后来继续编辑项目，不会改变旧交付物的内容。

文件搜索遇到无权读取的目录时，会保留其他位置的结果，并列出警告。出现警告或结果截断时，搜索可能不完整；“没有找到”不等于整个工作区都没有匹配内容。正则表达式或 glob 写错会明确报错，可以修改搜索条件后重试。

侧栏“文件”集中展示当前空间中有权访问的会话文件，可按工作区、会话、上传／生成和文件名筛选。会话顶部的“文件”入口打开同一页面并带上当前会话筛选。点击文件名预览，点击下载按钮保存对应版本；同名产物的旧版本不会被后来的修改覆盖。归档会话的文件仍可查看下载，原会话无法直接打开时可以筛选该会话的文件。电脑离线时会显示提示，托管文件已经保存在 Server 时无需 Worker 在线。

桌面文件页左栏用于文件类型、工作区和会话导航，右侧保留文件名搜索与结果；手机把这三项放入可展开的“筛选”区域。选中项有明确标记，筛选保存在 URL，刷新和直接链接仍可保留。切换工作区会清除原会话筛选，不切换聊天中的当前工作区或会话；筛选只影响已经有权查看的文件。

文件页顶部只提供已有空间的切换，不提供创建团队／空间按钮；桌面和手机一致。创建入口仍保留在工作台。

附件随任务提交成功后就会进入文件清单，不必等任务开始或 Worker 上线。移除排队任务、取消运行或归档会话后，已提交的附件仍可下载；删除所属会话时，文件清单中的对应记录才会移除。电脑上的附件会先同步文件信息，下载时仍需原电脑在线。浏览器未发送的草稿不属于已保存文件。

批量删除未分组会话时，可以点击“取消剩余删除”。已经发出的当前删除请求仍会完成，已删除会话不会恢复，尚未开始的会话不再删除；结束后显示删除和保留数量。失败后重试只处理剩余会话，不重复删除已完成项。删除会话仍不可撤销，但不会删除工作目录内的项目文件。

接入电脑在本地删除会话后，会通过持久化删除记录同步清除 Server 中对应的会话映射、共享关系、事件和附件信息。断线期间的删除在重连后补齐；仅仅离线或暂时未读取到会话不视为删除。迟到的旧事件或资源快照不会恢复已删除会话，同一账号另一台电脑的同名会话不受影响。Server 发起删除仍需原有删除权限，重复删除已不存在的记录不会再次操作目录文件。
